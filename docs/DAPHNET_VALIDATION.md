# Daphnet 真实数据验证记录

更新日期：2026-10-19。

## 目的与证据边界

本记录把公开、去标识的真实患者数据纳入机器人 1 的 P0 交付，用来回答“现有 FoG 基线在不同参与者上能否泛化”。它不等同于人体试验，也不用于证明提示策略的疗效。

- 数据源：[UCI Daphnet Freezing of Gait](https://archive.ics.uci.edu/dataset/245/daphnet+freezing+of+gait)，许可为 CC BY 4.0。
- 原始研究：[Bächlin 等，2010](https://pubmed.ncbi.nlm.nih.gov/19906597/)。论文报告 10 名帕金森病参与者、超过 8 小时记录和 237 次 FoG 事件；标签由同步视频与专业人员标注。
- 提示设计依据：[Cosentino 等，2023 系统综述](https://pubmed.ncbi.nlm.nih.gov/37086934/)。综述说明视觉、听觉等外部提示的结果受任务与指标影响，因此本项目分别评估检测、情境和提示规则，不把检测成绩写成提示有效性。

原始数据不提交到 Git；下载文件保存在已忽略的 `data/raw/`。下载脚本固定官方地址并校验 SHA-256：

```text
27C6173B3ACEE75A69284903756B9011A00766C1BBB743C37FC884C5DBC39399
```

## 数据映射与实验设置

- Daphnet 以 64 Hz 记录踝、股和躯干三处三轴加速度；本次主实验只用踝部传感器。
- 官方标签 `0/1/2` 分别表示协议外、非 FoG、FoG。导入时先按协议内连续区段切分，再映射为 `0/1`，避免窗口跨越协议外间隙。
- 官方加速度单位为 `mg`，导入时转换为 `m/s²`，并把竖直轴映射到项目的 `az`。
- 数据集没有陀螺仪。兼容列中的 `gx/gy/gz=0` 仅为缺失值占位，并设置 `gyro_available=false`；转向模块会拒绝这类窗口，不能把零值解释为“直走”。
- 使用现有 2 秒窗口和 0.5 秒步长，窗口内 FoG 样本比例至少 50% 时记为阳性。
- 采用按参与者留一法（leave-one-subject-out，LOSO）：每一折只用其余参与者选择阈值，再在完全留出的参与者上评估，避免同一参与者同时进入训练和测试。
- 阈值选择依次最大化训练折的 balanced accuracy、F1，再减少误报；候选阈值为 0.01–0.99，步长 0.01。

复现命令：

```bash
python scripts/download_daphnet.py
python scripts/evaluate_daphnet.py
```

本地逐折结果写入被 Git 忽略的 `reports/daphnet_loso_evaluation.json`。

“非 FoG 阳性窗口/分钟”统计的是重叠窗口，不是合并后的独立误报事件，因此不能直接等同于每分钟响铃次数。它仍清楚显示当前检测输出若逐窗口驱动提示，会造成不可接受的重复误报。

## 决策

1. 合成数据得到的阈值 `0.21` 继续只用于工程演示，不再称为真实数据阈值。
2. `0.73` 是 LOSO 各训练折所选阈值的中位数，不直接替换默认值。参与者间差异大，而且该阈值下 precision、F1 和误报仍不足以支持真实提示触发。
3. 当前 Freeze Index 作为可解释基线保留，用于演示信号处理、窗口评估和失败案例；不作为“已完成的可靠 FoG 检测器”。
4. 下游提示控制不能逐个阳性窗口触发。至少需要事件合并、持续性确认、不应期和恢复观察；这些工程规则也不能掩盖检测器本身的误报。
5. Daphnet 没有陀螺仪、转向真值、足部落点或提示后的响应数据，因此不能验证转向模块、自适应脚印或提示疗效。这些项目继续分别用带来源标记的仿真输入验证系统行为。

## 与原论文结果的关系

原论文报告的是作者算法与其事件定义下的灵敏度和特异度。本仓库使用不同的简化 Freeze Index、窗口聚合及 LOSO 阈值流程，所以不能把两组数字直接比较成算法优劣。原论文用于证明数据与标注来源，本记录用于诚实检验本仓库基线的跨参与者表现。
