# A1 失败信号可分性与双踝输入：固定协议

日期：2026-10-29。先审查真实TRAIN信号和右踝可用性，再按预定条件进行一个输入信息对照，不继续组合上一轮失败loss或扩大网络。协议与配置先提交；保持TRAIN14/VALIDATION4/TEST4及人员折，模型选择不看新TEST。

## 输入与覆盖审查

左踝gyro三轴60Hz，每个左踝连续有效段按120点/30点切窗。双踝窗口必须是同一左踝窗口原始120行，另要求右踝三轴全部有限；右踝缺失就无双踝预测，不填零、不插值、不悄悄重启右踝网格。时间戳需与60Hz规则一致。比较左右均使用gyro，不引入accel/腰背。

TRAIN先输出原始70条记录、左踝窗口、双踝可用窗口、按人缺测与事件/时间支持。门槛为双踝可用窗口占左踝>=80%，且每个既有外层拟合集含两类FoG；否则只交付审查，不重抽人或用插值跨过门槛。门槛是本轮工程可行性规则，不是临床标准。

## 失败片段与可分性含义

使用前轮control的TRAIN按人留出评分、既有阈值，寻找纯非FoG（当前120点全0）误报，与同参与者、同活动真值、纯FoG（全1）片段配对；同记录必须开始时刻相距至少6秒，不同记录不重叠。分别审查非FoG站立与左右转。若没有合适对，明确报告，不改条件选好看案例。

固定选择各组“既有左踝特征距离最近”的一对。StandardScaler只在TRAIN双踝可用特征拟合，距离为标准化特征欧氏距离/平方根维数，同时展示原始双踝gyro、窗口内去均值向量RMS和全部组分布。对是刻意挑最相近左踝特征，属于描述性失败审查，不是盲测，不证明输入理论不可区分或右踝必然有效。距离在不同维度下也不能直接解释为信息增益。

活动标签只是事后分组，未直接标注主动停步或主观意图；报告必须称“非FoG站立”，不能把它偷换成主动停步。FoG真值、窗口弱标签、原始事件、分类输出及提示响应分开。

## 条件满足后的两组RF

原始双踝可用窗口完全相同、训练人/折相同；左踝对照取前三通道33个既有统计特征，双踝取六通道66特征。滤波/频谱均限已完成2秒窗口，沿用0.5–20Hz和每轴11项特征。只增加右踝输入，不加协同手工特征、历史、增强、人员权重、辅助头或新后处理。

固定300树、min_leaf2、balanced_subsample、seed5412。按既有TRAIN外层折拟合并产生OOF，不需要内层选RF超参；每人评分来自未拟合此人的模型。只用TRAIN-OOF选91点F1/BA/较高阈值；再从零拟合全部双踝可用TRAIN窗口，实际有窗口的拟合人员如实列明。OOF成绩参与校准，不称独立测试。

MODEL_LOCK写入后才单独评价VALIDATION4。比较同一双踝窗口的Precision/Recall/F1/AP、事件/误报时间/冻结时间Recall；另用已冻结左踝模型评价其自然全部左踝窗口，显式展示双踝依赖造成的可用范围损失。保留每个角色全部原始记录和事件，不用缺测当正常。预定研发条件：共同窗口双踝F1更高、误报时长不增加、冻结时间Recall不降低，且双踝时间支持不低于自然左踝。满足也不自动替换默认，验证队列已被研究，外部泛化仍未证明。
