# A1 旋转不变表征单因素对照 v1

2026-10-29。此前FoG-STAR VALIDATION及Stanford结果均已查看，本轮是目标问题启发的研发，不是新盲测。不触碰封存TEST，不旋转目标找最优方向。

唯一实验因素为输入表征：现有双踝逐轴66维，对比固定10维旋转不变摘要。后者直接沿用上一轮已核验的定义：完成120点/60Hz窗口内，四阶0.5–20Hz Butterworth sosfiltfilt；逐踝合成RMS、三轴rFFT能量和/120²的0.5–<3Hz功率、3–8Hz功率、两者比值（分母至少1e-12）、步态带峰频（功率<=1e-12返回0）。左右分别计算，不交换左右，不做幅度/目标分布归一化。不增加协调、缩窗、历史、损失、增广、门控或后处理。10维压缩也会丢信息，本实验不将其结果解释成纯轴校准的因果效应。

RF政策固定：300棵、min_samples_leaf=2、balanced_subsample、random_state=5412，其余使用现有sklearn默认，包括max_features=sqrt。维数改变时sqrt所取候选特征数自然改变（66维8、10维3），不另调参数；应明示这一实际行为，不声称每个树节点具有相同候选数。重新训练两种表征，各3个按人TRAIN折及最终TRAIN模型。66维OOF和VALIDATION概率/判断必须复现已有基线。

固定14/4/4人、旧三折计划、6383个TRAIN双踝窗口。阈值各自用TRAIN按人OOF的0.05..0.95共91点选FoG F1最大，平局balanced accuracy、较高阈值，与旧流程一致；不是强制候选用0.23。模型/源代码/数据/阈值先锁定，随后单独评价2014个VALIDATION窗口、全部20条原始记录/10个事件。分数从已完成窗口末端起可用、最多保持0.5秒；缺测未知，不补零。

沿用开发门槛：相同窗口F1更高、原始误报秒数不增加、FoG时间Recall不降低、决策支持不减少，四项全部成立才算通过本轮开发门槛。无论是否通过，都保留结果，不追加候选或按成绩修改本协议；通过也不自动替换默认模型。

锁定后只做一次Stanford研发复查：全部60记录/7人/10033既有窗口，读取旧锁定适配NPZ；同原单位转换、因果采样及1/6秒延迟、未知规则、原xyz、原始211事件。对照沿用旧锁定66维分数，候选用新TRAIN模型及TRAIN阈值；窗口标签沿用旧锁定同键真值，原生真值从旧锁定truth intervals和128Hz时间重建，不重定义事件。全部人/记录保留，不以P6/P7改善替代总体结果。目标来源已用于问题发现，任何改善都不是独立泛化证明，也不得再按复查成绩调参。

新增模块级FoG-only推理入口、模型/阈值/输入来源锁、逐窗/逐人/活动及原始事件时间表。独立核验10维公式、正交旋转与符号不变性、原始网格/真值、各TRAIN折模型重载评分、人员隔离及阈值复算、VALIDATION/外部时间度量、无真值推理、已有控制复现。全项目检查含recognition和旧真实数据审计。输出新版本目录及展示PNG/SVG/HTML，不覆盖旧实验，不把数据、模型或生成目录提交Git。

旋转不变不等于幅度不变、左右互换不变、身体状态不变或不同佩戴位置不变；两秒滤波只用已完成窗口，不代表硬件实时延迟。无转向意图/迈步成功/提示疗效标签，本轮不改变A2/控制器/共享接口。
