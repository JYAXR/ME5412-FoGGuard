# 汇报：三种冻结识别方法

正文只讲三种方法：[实现与指标总表](SELECTED_METHODS.md)。不再讲全部研究历程。

1. 左踝历史RF：左踝加速度和角速度，当前66维加历史摘要共140维，300棵树，阈值0.18。同窗F1 0.6912、Recall 0.8979、误报166.88秒。
2. 双踝gyro RF：左右踝角速度，2秒66维特征，300棵树，TRAIN按人OOF阈值0.23。同窗F1 0.6860、Recall 0.8574、误报153.28秒。
3. 左踝gyro CNN：去均值波形，经四层causal卷积和Dense48得到FoG分数，8353参数，开发验证早停及阈值0.50。同窗F1 0.6772、Precision 0.6715、误报82.23秒，但事件只触及8/10。

同一4人、20记录、2014窗口/470阳性。输入和训练选择流程不同，属于研发方案比较，不是算法家族的严格单因素优劣证明。事件触及不等于完整检出或准确率。

## 一分钟讲稿

“我们保留三种互补的冻结识别方案。左踝历史随机森林同时使用加速度与角速度，结合最多六秒的已发生运动信息，在同一验证窗口上F1最高，为0.691。双踝随机森林只用左右踝角速度，F1接近，为0.686，误报略少。卷积网络直接学习单踝角速度波形，精确率最高、误报时间最短，但漏掉更多冻结。

因此我们不将某个单一数字解释为全面最优。三种方案都保留完整误报与漏检指标，并提供统一推理入口。A2直接消费FoG输出，再对齐自己的方向结果，后续控制还需要独立的迈步反馈。现有结论来自开发验证，跨人及跨来源的稳定泛化仍需要更多证据。”
