# A1 冻结识别汇报

## 三种方法

1. 左踝历史特征 RF：左踝加速度和角速度，当前与过去运动摘要共140维，300棵树，阈值0.18。F1 0.6912、Recall 0.8979、误报166.88秒。
2. 双踝 RF：左右踝角速度，两秒66维特征，300棵树，TRAIN按人OOF阈值0.23。F1 0.6860、Recall 0.8574、误报153.28秒。
3. 左踝 CNN：去均值波形，经四层卷积和Dense48输出FoG分数，8353参数，开发验证早停及阈值0.50。F1 0.6772、Precision 0.6715、误报82.23秒。

成绩来自同一4人、20记录、2014窗口/470阳性的开发验证数据。输入和训练选择流程不同，属于方案比较；事件触及不等于完整检出或准确率。

## 一分钟讲稿

“我们的冻结识别模块提供三种方法。左踝历史特征随机森林结合当前与过去的运动信息，F1为0.691，召回率最高。双踝随机森林只用左右踝角速度，F1为0.686，可供A2先完成方向与冻结的接入。卷积网络直接学习单踝角速度波形，精确率最高、误报时间最短，但漏掉更多冻结。

A1已交付模型、效果比较和统一推理入口。A2负责方向和感知融合，B1负责运动反馈及提示切换，B2负责联合评估。最终可视化由工业设计读取保存结果制作。当前模型成绩是开发验证结果，稳定泛化与完整系统效果需要分别验收。”
