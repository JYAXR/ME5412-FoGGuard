# FoGGuard A1 阶段汇报摘要

2026-10-29。配套演示为10页正文、2页实验附录，逐页讲稿及来源写入PPT备注。本阶段收敛证据与交接，不为汇报继续增加候选。

## 结论

**已有局部改善和可复现的FoG研究基线，但跨人、跨数据集的稳定识别仍未解决。** 部分方法减少误报却增加漏检，尚不足以宣称整体可靠或验证临床效果。

## 完成了什么，达到什么效果

完成真实数据审计、参与者隔离训练、RF/SVM/梯度提升/CNN/GRU及特征/目标对照、原始事件和时间评价、失败回放及FoG推理接口。[全部实验](EXPERIMENT_INDEX.md)保留具体尝试和来源。

最清楚的单因素改善来自双踝输入：同流程、相同2014个验证窗口，左33维到双66维，F1从0.6234到0.6860，误报时长181.95降至153.28秒，冻结时间Recall从0.7827到0.8451。它通过该轮开发门槛，但双踝要求减少部分TRAIN输入支持，也未全面胜过历史模型。

此前四人内部TEST属于另一个锁定的六秒RF加左踝备用，1605窗F1为0.5307、Precision0.3850、事件20/23。模型、窗口池和人群不同，不能与0.6860直接排名；最新双踝没有新内部TEST成绩。

## 主要问题

- 外部个体差异大：P6 F1为0.063、事件只触及1/19，P7为0.261、12/48。平均分不能保证个体效果。
- 80个完全漏报事件中78个已有及时的事件自身多数窗口；纯FoG也可能低分，不能仅归因为事件太短。
- 轴向、幅度、任务和标注条件存在差异。图示仅支持条件名义轴映射，尚未逐试验校准；旋转不变摘要的差异仍不能证明错误因果。
- 反复用于开发的VALIDATION与Stanford不再是新盲测。重叠窗口不是独立患者样本。
- FoG检测不等于转向意图或迈步成功。原地踱步切换和最终展示还需下游独立证据。

## 可直接讲的三分钟版本

“我们先按参与者隔离数据，建立了能输出冻结分数、可用时刻和未知区间的检测流程。之后尝试传统机器学习、CNN、GRU、历史特征、加权及协调摘要，没有发现能同时解决误报与漏检的配置。

其中，增加另一只踝的角速度是一次明确的局部改善：同窗口F1从0.623提高至0.686，误报时间下降约16%。但这只是在开发验证集上的改善。外部七人迁移的F1为0.566，冻结时间覆盖只有48.7%，说明泛化仍不足。

进一步审查发现，80次完全漏检里78次已存在及时且包含足够冻结样本的窗口。只用10维不变摘要替换66维后，F1反而下降。因此我们保留基线和失败证据，不把少报警包装成算法升级。

本阶段交付的是可复现的研究原型、真实回放和清楚的能力边界。A2可以直接消费FoG输出，独立完成方向与融合。迈步反馈及原地踱步仍需各自证据。”

## 答辩简答

**是不是都没提高？** 有局部改善，双踝输入最清楚；尚未获得稳定、全面的泛化提升。

**为什么不继续换网络？** CNN和GRU尚未消除人员差异和误报取舍，继续研究需要明确假设及未参与开发的证据。

**贡献如何表述？** 可重复的参与者隔离对照、双踝消融、缺测和因果时间处理、失败分析及可交接接口。证据不足以声称提出领先算法或验证临床创新。

**A2现在能做什么？** 从[唯一交接入口](../A1_A2_START_HERE.md)运行保留模型，按记录键与可用时刻融合方向输出，无需重跑全部A1实验。
