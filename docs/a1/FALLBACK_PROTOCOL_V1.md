# A1：左踝备用输入 v1

日期：2026-10-29。输入可用性审计发现，原左踝/腰背组合有 95 条有效记录、83 个事件获得时间支持；单左踝有 101 条有效记录、95 个事件获得支持。支持只是存在传感器窗口，不表示能正确识别。

本轮独立训练固定左踝 RF，仅在主模型没有新鲜有效判定时补充。保留原六秒上下文 RF 的全部有效评分、阈值和判定；不按真值、活动、分数高低或事后效果切换模型。不将缺失腰背填零，不更改已观察的历史主模型。

左踝六通道、60Hz、二秒窗口/半秒步进。原 66 个高通统计特征，增加二秒/四秒前 RMS/步态频带/冻结频带摘要、差分和可用标志，共 140 项。记录/断档重置，保留启动窗口。固定 RF 300 棵、叶最小 2、balanced_subsample、seed5412。与原相同五折参与者隔离；阈值只由该折训练人的三折 OOF 的 FoG F1、balanced accuracy、较高阈值选择。全量部署另做同规则内层选择。

两条预测流按已完成窗口的结束时刻因果合并。每条主模型输出保留；左踝到达时，若过去半秒有主模型判定则忽略，忽略的到达不能延长主模型有效期；同刻主模型优先。没有有效左踝窗口仍输出未知/无预测，不宣称连续覆盖。不会借用未来主模型输出撤回过去的左踝决定。

新增窗口与旧 9,636 个窗口的集合不同。只将相同原始 106 条记录、101 个逐点事件的事件/时间成绩作为主要可比结果；报告两条模型各自窗口成绩，但不能把更大的窗口池的 F1 当作同窗口算法提升。验证主模型全部旧窗口完全保留、额外行来源与所需通道有限、每行原始 120 点标签和半秒有效期、全部事件、双方受试者隔离与路由无真值。

融合后的混合输入不能交给只按统一十二通道核验的旧窗口核验器并伪称通过。本轮单独逐行核对相应原始通道和标签，并用原有逐点区间算法交叉核对事件与时长。运行与评估真值分离，保存所有输入/代码/配置/模型哈希及来源；不替换默认，不宣称患者响应效果。
