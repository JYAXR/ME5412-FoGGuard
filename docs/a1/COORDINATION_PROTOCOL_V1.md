# A1 左右协调摘要：训练前固定协议 v1

2026-10-29。承接双踝输入对照，在完全相同输入上只增加一个12维左右协调摘要块：66维双踝基线与78维候选。继续使用TRAIN14/VALIDATION4/TEST4及既有TRAIN人员折，无新TEST评分。不叠加loss、历史、网络、增强、活动门控或后处理；本协议及配置在训练前提交。

## 特征的确切含义

只读取已完成120点/60Hz窗口的左右gyro。沿用左锚定120/30网格、双踝完整性、0.5–20Hz四阶Butterworth窗口内sosfiltfilt；没有窗口结束后的样本。记滤波后的左右三轴为L/R，向量模长包络a/b，三轴总均方能量E_L/E_R，eps=1e-12。

1. 能量有符号不对称(E_L-E_R)/(E_L+E_R+eps)。
2. 上项绝对值。
3. mean(abs(a-b))/(mean(a)+mean(b)+eps)。
4. a/b去均值、单位范数后的零延迟相关；任一范数<=eps返回0。
5. -30..30采样点重叠段分别去均值后的最大相关（至少90点重叠）；静态退化段相关0。
6. 上项最大相关对应延迟的绝对秒数。遍历顺序按(abs(lag),lag)，相等取先到，故全零取0。
7. ±15点（0.25秒）两个相关的均值。
8. ±30点（0.5秒）两个相关的均值。
9. 双侧三轴rFFT功率之和在0.5<=f<3Hz内求和，有符号不对称。
10. 同上，在3<=f<=8Hz内的不对称。
11. 双侧0.5<=f<3Hz总三轴功率向量的余弦相似度；任一范数<=eps返回0。
12. 同一gait频带最大功率频率的绝对差；任一频带总功率<=eps返回0，并列取最低频。

这些是短窗运动协调**代理量**。模长包络的相关延迟不是已验证的左右脚落地相位、步长、迈步成功或冻结提前预测。零能量保护是数值约定，不是临床静止阈值；不把缺测当零能量。新增12维独立正交轴旋转下不变，但保留的66维轴向特征及整个模型不保证旋转不变。左/右交换时有符号不对称翻转，其余定义对称。
