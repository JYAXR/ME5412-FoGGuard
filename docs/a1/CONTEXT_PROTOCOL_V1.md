# A1：六秒因果上下文固定实验 v1

日期：2026-10-28。前轮困难负样本加权未改善结果；本轮只运行一个固定历史特征候选，检验额外传感器时序信息能否改善当前二秒窗口的判别。原模型、控制器及方向预测不变。此队列已被反复查看，本轮仍为探索，不能宣称全新外部验证。

## 输入与唯一候选

沿用左踝/腰背 12 通道、60 Hz、二秒窗口、半秒步进、不插值。窗口真值仍为当前 120 样本中 FoG 占比至少 50%，不是未来冻结预测。基线是原 132 特征 RF；候选在此基础上增加：

1. 二秒前和四秒前各一个已经结束的二秒窗口。三个不重叠窗口共覆盖最长六秒；没有使用当前决策之后的样本。
2. 每个历史窗口取 12 通道的 RMS、gait_energy、freeze_energy，共 36 项，加入其历史值和当前减历史值，共 72 项。
3. 每个历史偏移再增加一个可用标志。候选合计 132 + 2 × (36 + 36 + 1) = 278 项。

频带统计来自现有已完成二秒窗口内的 0.5–20 Hz 滤波及原频谱实现。并未对整段数据先做双向滤波。历史窗口的标签、活动、旧模型评分、个人编号均不作为特征；记录键只用于清空历史。

历史不足时，历史摘要复制当前摘要，差分为零，可用标志为零。这是明确的历史编码，不是填补缺失传感器。每个原有效窗口仍输出一次判定，不等待六秒，不丢弃开头困难片段。不同参与者/session/task 或窗口步进不是 0.5 秒时重置；同记录重复或倒序窗口报错。

## 训练与判定

配置在 config/a1_context_v1.json 固定：RF 300 棵、叶最小 2、balanced_subsample、seed5412，两组相同。保留旧五折外层参与者划分，训练参与者内部相同三折选阈值；91 个 0.05–0.95 阈值按 FoG F1、balanced accuracy、较高阈值排序。没有历史长度搜索或依据外层成绩调参。

历史特征可在分折前无监督计算，因为不估计队列统计、不看标签，且每个历史引用都限定同记录、同连续窗口段、早于当前。随后以整个人划分训练和验证。保存每个窗口两项历史行号及可用标志，由另一核验脚本逐项重建检查。

全量模型另行拟合，阈值沿用五个训练内阈值的中位数；全量模型训练回放不作为留出成绩。scores 字段沿用 fog_probability，未增加概率校准。运行时模型提供整段回放和 new_stream().push(window) 两种路径，后者每个独立输入源分别保留最多九个已完成窗口。逐个窗口单独调用 predict_windows 会重启历史，不等于持续流；二秒前/四秒前历史缺失标志须保留给 A2。

## 评估与展示

严格复核与原 9,636 个窗口同键同真值；两组从相同窗口结束时开始提供判定。全部 106 条原始记录和 101 个冻结事件计入事件/时间评价，不删除 11 条无预测记录。报告 P/R/F1/AUC/AP、逐人/活动错误、误报警事件、任意重叠覆盖及条件延迟。

另报告开头/历史不全与六秒历史完整两组表现，这是事先声明的描述性分析，不据此切换模型。展示方法时间图、指标对比、逐人变化和按数据顺序首个含 FoG 且有完整历史的记录的留出回放；在训练前将回放选择依据写入协议，不挑选最大改进案例。

核验：未来原始样本和标签不能改变过去输出、历史/跨记录断档重置、保留启动窗口、批处理/逐窗流一致、保存加载一致、同人员分折、阈值规则、原始样本标签重建、运行时不含 truth_*、输出哈希。默认模型不自动替换。
