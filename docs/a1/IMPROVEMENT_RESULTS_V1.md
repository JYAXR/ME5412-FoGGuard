# A1 继续改进：模型选择、输入备用与联合候选

日期：2026-10-29。目标是实际改善冻结识别，不以接口跑通或 F1 单一指标宣布达标。方法分别见 [姿态特征/模型选择](POSTURE_SEARCH_PROTOCOL_V1.md) 和 [左踝备用](FALLBACK_PROTOCOL_V1.md)，部署调用见 [接口交接](IMPROVEMENT_HANDOFF_V1.md)。原默认模型和控制器没有替换。

## 本轮结论

得到一个可继续研究的联合候选：在同一 106 条原始记录、101 个冻结事件上，相比此前六秒 RF，事件覆盖 70→75，冻结时间 Recall 59.85%→64.41%，报警时间 Precision 53.57%→57.88%，误报警事件 235→232。未检出的事件仍有 26 个，不能称为高准确率或完整解决。

联合方案由训练内选择主模型与左踝输入备用组成。主模型选择在训练参与者内部完成；备用只按当前输入可用性切换，不按标签或事后成绩切换。联合组合是在观察两组件结果后提出，仍使用已多次探索的旧队列，不是全新独立验证。所有成绩为参与者留出评分的探索性评价，没有预训练权重或目标测试人标签微调。

## 1. 严格训练内诊断与模型搜索

先前模型只用高通后的主要统计；本轮增加原始均值、方向代理、缓慢角速度和两位置协调摘要。输入仍为左踝/腰背，基础六秒 278 特征增加到 438 特征。数据真值、站立和边界窗口没有删除或重标。

每个外层训练集合内比较六个固定配置：旧六秒 RF、新特征 RF 的叶最小 2/8、新特征 ExtraTrees 的叶最小 2/8、新特征 HistGB。先以内层三折 OOF 选阈值，再按内层 F1、AP、既定顺序选择配置。外层四折选旧 RF，一折选新特征 ExtraTrees。全量部署另外三折选择了 posture_extra；不能将这个全量模型的训练回放当下表成绩。

| 相同 9,636 个窗口 | 旧六秒 RF | 新特征固定 RF | 训练内选择流程 |
|---|---:|---:|---:|
| Precision | 0.5534 | 0.4873 | 0.5906 |
| Recall | 0.7016 | 0.6078 | 0.6790 |
| FoG F1 | 0.6188 | 0.5409 | 0.6317 |
| AUC | 0.8691 | 0.8476 | 0.8641 |
| AP | 0.6631 | 0.6226 | 0.6552 |
| 原始事件有报警重叠 | 70 / 101 | 74 / 101 | 69 / 101 |
| 误报警事件 | 235 | 211 | 207 |

新特征直接接 RF 的假设失败；训练内选择器保留了多数旧配置，F1 和精确率有小幅改善，但召回、AUC/AP 和事件覆盖下降，不能称整体全面更好。不存在外层逐人挑最佳配置后拼分的操作。

第一外层 TRAIN 的 18 人、7,308 窗口另生成新内层 OOF 诊断，排除该折四位测试人：纯负窗口有 781 次误报，纯冻结窗口有 238 次漏检；混合边界窗口有 87 次误报、94 次漏检。说明问题不能只归因于边界标签。活动与冻结表现真值仅作分层，不进入推理或直接否决。

## 2. 左踝备用改善数据支持

左踝/腰背输入只能支持 83 个事件；同数据仅要求左踝可支持 95 个。另训练固定六通道、140 特征的左踝 RF，采用相同五折测试人和训练内阈值选择；主模型评分、阈值及 9,636 条判定全部保留。

每条主判定最长新鲜半秒，只在没有新鲜主判定时补左踝。被忽略的左踝到达不延长主判定有效期；CSV 时间的微小舍入按原审计一微秒精度匹配，原时间字段保留。没有填补缺失腰背，也没有借用未来主预测。

| 相同 106 条记录、101 个事件 | 旧六秒主模型 | 旧主模型＋左踝备用 |
|---|---:|---:|
| 有预测记录 / 有时间支持事件 | 95 / 83 | 101 / 95 |
| 判定行数 | 9636 | 10274 |
| 检出事件 | 70 | 76 |
| 冻结时间 Recall | 0.5985 | 0.6655 |
| 报警时间 Precision | 0.5357 | 0.5469 |
| 误报警时长（秒） | 556.17 | 591.08 |
| 误报警事件 | 235 | 260 |

新增 638 条有效备用判定，恢复支持的 12 个事件中检出 6 个。代价是多 25 个误报警事件、约 34.92 秒误报警。新增支持不是全部准确检测；还有 6 个事件完全无支持。左踝模型自身在 10,274 窗口上的 F1=0.6269，但窗口集合不同，不能把它与主模型 F1 当作同窗口对照。

## 3. 冻结组件的联合评价

不再拟合或搜索参数，把训练内选择主模型与同一左踝备用按同一可用性规则组合。两个组件外层测试人完全相同，测试人的标签都没有参与各自训练。该组合是在两组件结果出现后提出，因此明确记为后续探索，而非新的确认性验证。

| 全部 106 条原始记录 | 旧六秒 RF | 选择主模型＋左踝备用 |
|---|---:|---:|
| 检出 / 全部真实事件 | 70 / 101 | 75 / 101 |
| 完全未覆盖事件 | 31 | 26 |
| 无模型支持事件 | 18 | 6 |
| 真冻结报警时长（秒） | 641.62 | 690.60 |
| 误报警时长（秒） | 556.17 | 502.47 |
| 时间 Recall | 0.5985 | 0.6441 |
| 时间 Precision | 0.5357 | 0.5788 |
| 误报警事件 | 235 | 232 |
| 条件新报警延迟中位数（秒） | 1.2833 | 1.3333 |

原 9,636 个窗口使用所选主组件，其 Precision/F1 为上表的 0.5906/0.6317；新增备用窗口单列，不混成“同窗口 F1 大幅提高”。联合候选保留所选主组件的全部决定，并不保留旧 RF 的全部决定。冻结事件任意重叠不是一对一事件 F1，条件延迟分母分别为 55 和 60，不含漏掉或预先报警的事件。暂未评价原默认集成器额外确认/恢复后的提示成绩，也没有冻结前提前预测、真实迈步或患者响应证据。
