# A1：训练内困难负样本诊断与加权 v1

本轮聚焦既有模型的非冻结误报。先在第一外层折的训练参与者内部生成描述性诊断，再运行一个固定的训练加权候选。参数在新结果出现前写入 config/a1_hard_negative_v1.json，不根据外层成绩修改权重或挖掘阈值。

这是已被项目反复分析的同一公开队列上的后续探索。训练和验证过程仍隔离参与者，但研究者已看过先前外层结果，因此不能称为全新外部验证。

## 先诊断什么

诊断只使用第一外层折的 TRAINING 参与者，明确排除该折四个测试参与者。训练内部做两折参与者留出，给每个训练窗口生成一次未见该参与者的分数。

描述四组：真实窗口 FoG、含少量 FoG 但未达 50% 的混合负窗口、高分纯负窗口、其余纯负窗口。比较动态踝部 RMS、躯干角速度 RMS、踝部高/低频能量比的四分位数及分布，按活动真值列出计数。该分析不把重叠窗口当成独立患者做显著性检验。

活动真值只用于描述训练样本。模型推理、挖掘准则和事件控制均不读取 activity 标签。

## 唯一候选

共同使用原 132 个特征和 RF（300 棵树、叶最小 2、balanced_subsample、seed5412）。

- baseline：原训练方法，所有样本的额外权重为 1。
- hard_negative：该次训练集内部两折参与者留出分数至少 0.30，且窗口逐点 FoG 占比恰为 0 的负窗口，额外权重为 2；其余样本为 1。

实际权重还乘以原 balanced_subsample 的类别权重。没有改真值、没有删正常数据、没有将站立一律标为非冻结。

含少量 FoG 的负窗口不加负权，以免直接将启动/恢复边界当作需要重点惩罚的纯负样本。真实 FoG 也不加负权；这不保证模型不会漏检，它只是明确训练操作的边界。

## 隔离层次

外层测试人 → 内层验证人 → 挖掘子折人，三层职责不同：

1. 固定五个外层测试参与者集合，与前两轮相同。
2. 外层训练集内部三折选择 FoG F1 优先阈值，与多模型比较保持一致。
3. 对每个内层训练子集，再在它内部做两折挖掘，然后加权拟合。相应内层验证参与者不能进入挖掘或拟合。
4. 外层模型的困难样本只从完整外层训练集内重新挖掘，不能读取外层测试人。
5. 全量部署模型最后另行训练，不把其训练回放当外层验证。

不能直接拿上轮全队列 OOF 筛选“外层训练的困难样本”，因为某些旧 OOF 的训练模型可能见过当前外层测试参与者。本轮全部挖掘分数在正确子集内新生成。

阈值从 0.05–0.95 共 91 个值选择，优先内层 FoG F1、其次 balanced accuracy、最后较高阈值。加权倍率 2 和挖掘界限 0.30 是预先固定的工程选择，不声称已被优化或具有临床依据。

## 实现与复现

- src/fogguard/evaluation/a1_hard_negative.py：参与者隔离检查、子折评分、纯负权重、内层阈值。
- src/fogguard/modeling/a1_hard_negative.py：保存训练变体版本；推理复用原传感器 RF 路径。
- scripts/run_a1_hard_negative.py：训练诊断、基线/候选、独立原始核验、图表和交接输出。

```powershell
python -X utf8 scripts/run_a1_hard_negative.py --baseline-dir reports/readiness_20261028_verified
```

输出采用新的 reports/a1_hard_时间戳/。包含 training_only_profile.csv、training_profile_summary.csv、training_activity_profile.csv 和排除人员审计，以及两组模型、OOF、独立真值、A2 runtime、三层折清单和训练权重。

独立推理仍可使用 predict_a1_multimodel.py 读取 model.joblib；模型版本输出为 a1_hard_negative_v1/变体。A2 不需要活动真值或训练权重来推理。

## 完成判断

比较窗口 P/R/F1/AUC/AP、全部 106 条记录的真实事件/时间覆盖、漏检/误报警及逐人/活动表现。检查原 RF 基线是否与上一轮相同规则的 RF 数值复现。

保留成功和失败的结果；不自动替换默认模型。即使误报减少，也要检查召回和事件延迟代价。单轮探索结果不证明患者疗效或跨新队列泛化。
