## 训练与锁定

固定八个配置：二秒 RF、SVM、HistGB、CNN、ExtraTrees；六秒 RF；六秒姿态 ExtraTrees；单左踝 RF。前五条使用相同当前二秒原始输入，表格 RF/SVM/HistGB/ExtraTrees 使用 132 特征，CNN 使用同一窗口波形；后两条十二通道模型使用已实现的 278/438 历史特征。左踝模型 140 特征、可用窗口集合单列。树数/叶、CNN 20 轮及随机种子固定，没有测试早停。

所有拟合、SVM scaler、CNN normalization 及噪声标准差只取 TRAIN。VALIDATION 只选择每个模型的 91 项阈值（FoG F1、balanced accuracy、较高阈值），并在七个主模型间按验证 F1、AP、既定顺序选主模型。固定左踝 RF 仅在主预测缺失时备用，不能按标签或测试评分切换。模型不在验证或测试后重拟合，保持其 TRAIN-only 状态以供后续真正按人留出的内部复查。

训练脚本只构造 TRAIN/VALIDATION 窗口；保存八个模型、验证评分、全部阈值成绩及噪声统计后，写 TRAINING_LOCK.json 记录模型/配置/来源哈希、拟合人员及验证选择。在独立测试脚本开始前检查锁。测试阶段不含模型 fit，不修改模型或阈值；如测试结果不好也保留，不据此继续挑参数或更换测试人员。

## 测试与扰动

先前已讨论鲁棒性，本轮预先固定七种 TEST 场景：原信号；训练通道标准差的 5%/15% 高斯噪声；两位置一致 15° 安装方向旋转（acc/gyro 同一旋转）；两位置 gyro z 偏置 +3 deg/s；腰背/左踝各每十秒连续缺测一秒。范围是工程压力条件，不能声称真实传感器误差分布。噪声参数从 TRAIN 保存，TEST 不参与估计；扰动不改时刻或冻结/活动标签，也不制造新的真实冻结。

每个场景同一原始 TEST 人群和逐点事件分母。缺测会减少有效窗口，必须同时报告有预测时的窗口 P/R/F1 与全部原始 TEST 记录的事件覆盖、时间 P/R、误报、无预测支持。联合模型的额外窗口单列，不能把不同窗口池 F1 当相同样本提升。轮转跨折成绩与本次单固定划分不能直接混为同一测量。

验证集选出的主模型在测试前固定；测试表会列出所有模型，但不能事后将测试分数最高者称为验证选中的胜者。报告逐 TEST 人结果、错误案例、模型比较及压力下降图。仍不验证提前预警、真实迈步、患者响应或最终提示治疗效果，原默认/共享类型保持不变。
