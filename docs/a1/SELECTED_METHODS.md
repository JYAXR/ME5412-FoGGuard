# A1：三种冻结识别方法

A1 已完成三种冻结识别方法、统一推理入口与效果比较。三种方法分别体现时序特征、双踝信息和波形学习的取舍。

## 方法1：左踝加速度和角速度的历史随机森林

标识`ankle_history_rf`，实现`modeling/a1_ankle_history.py`。

一个左踝IMU提供加速度xyz和角速度xyz，60Hz。每次取完成的120点窗口，在窗口内做0.5–20Hz滤波。逐轴提取11项统计/频带特征，得到66维。再加入前2秒、前4秒对应窗口的RMS、步态/冻结频带能量、与当前的差值及历史可用标志，共140维。缺历史使用明确标志，记录切换或断档时重置，不读取未来。

训练300棵RF，最小叶2点，balanced_subsample，seed5412。14人训练、4人开发验证选F1阈值，当前为0.18。它在这三种方法的同窗比较中F1最高，但误报时间最长。

## 方法2：双踝角速度随机森林

标识`bilateral_rf`，实现`modeling/a1_bilateral.py`。

左右踝各提供角速度xyz，共6轴。使用相同完成的两秒窗口及0.5–20Hz滤波，每轴11项统计/频带特征，共66维，不使用更早历史。左踝连续段决定切窗网格，右踝缺失跳过原窗口，不补零、不重新开网格。

RF参数同方法1。阈值从TRAIN14内部按人三折OOF选择，当前为0.23，再拟合全部TRAIN。它只需gyro，F1接近方法1，误报略少；需要两只踝的有效输入。A2可先用它接通接口。

## 方法3：左踝角速度CNN

标识`ankle_cnn`，实现`modeling/a1_author_cnn.py`。

只使用左踝角速度xyz的120点波形。每个窗口独立去均值，不使用RF的频带滤波或人口标准化。四层causal卷积通道16/16/24/24、卷积核9/7/5/5，池化4和3，dropout0.4，全局平均、Dense48及一个FoG输出，共8353参数。卷积只在已完成窗口内部计算，不表示能够提前预测冻结。

使用AdamW和BCE从零训练，训练最多120轮，开发验证早停，实际17轮并恢复第7轮，阈值0.50。它误报时间最少，但漏掉更多冻结。结构来自[公开作者代码](https://github.com/Lu1g1n0/FoG-detection-using-a-single-ankle-mounted-sensor)，论文DOI `10.1177/1877718X241302766`；属于架构复现和流程适配，没有作者预训练权重，也不声称原创该CNN。

## 同一组窗口的效果

4位开发验证参与者、20条原始记录、2014个窗口、470个阳性窗口、10个原始冻结事件，约17.84分钟观测。三种方法的记录键、窗口和真值逐行一致。输入和阈值/检查点选择流程不同，这是已训练方案的比较，不能全部归因于分类器家族。

| 指标 | 左踝历史RF | 双踝gyro RF | 左踝gyro CNN |
|---|---:|---:|---:|
| Precision | 0.5619 | 0.5716 | **0.6715** |
| Recall | **0.8979** | 0.8574 | 0.6830 |
| FoG F1 | **0.6912** | 0.6860 | 0.6772 |
| AP | 0.7036 | 0.6294 | **0.7314** |
| TP / FP / FN / TN | 422 / 329 / 48 / 1215 | 403 / 302 / 67 / 1242 | 321 / 157 / 149 / 1387 |
| FoG时间Recall | **88.46%** | 84.51% | 66.80% |
| 误报时间 | 166.88s | 153.28s | **82.23s** |
| 原始冻结事件有报警重叠 | 10/10 | 10/10 | 8/10 |
| 判定时间支持 | 93.72% | 93.72% | 93.72% |

事件有一次正重叠就计为触及，不是100%准确率或事件F1。没有预测的时段是未知。FoG F1不等于Accuracy；当前任务是冻结/非冻结检测，不是冻结前预警。

表内为开发验证结果，模型与阈值选择使用相应的开发流程，不能称为独立最终测试。双踝 RF 的 Stanford 外部迁移 F1 为 0.5657、冻结时间 Recall 为 48.74%，适配单位与采样但未逐试验统一轴系。另两种方法没有外部成绩，稳定泛化尚待验证。

## 可复现入口

只保留三个训练选项：

```powershell
python -X utf8 scripts/train_selected_fog.py --method all --output reports/selected_train_NEW
python -X utf8 scripts/evaluate_selected_fog.py --bundle reports/selected_train_NEW --output reports/selected_review_NEW
```

训练采用14/4/4人角色，只有TRAIN/开发验证构造窗口，当前入口不评分TEST。各方法采用各自的阈值政策，不把CNN验证早停与双踝TRAIN-OOF校准写成相同训练预算。

模型包和评价输出提供哈希清单。A1 交付包括三模型权重、配置、推理/评价/打包入口与合成接口样例；方向、运动反馈及四模块联调分别由 A2、B1、B2 完成。

下游接口及A2分工见[交接入口](../A1_A2_START_HERE.md)。
