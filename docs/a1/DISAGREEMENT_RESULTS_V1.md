## 时间分歧揭示什么

逐原始采样格重建预测归属：窗口末端才起效，最多保持0.5秒/下次预测。无输入支持保留未知，不能用插值把缺口补成正常或FoG。与上轮EventSupport、comparison和逐事件event_coverage交叉核对一致。

| 原始时间变化 | 时长 |
|---|---:|
| 原双踝报警、协调模型不报警的FoG时间 | 17.10s |
| 原双踝未报、协调模型新增报警的FoG时间 | 0.50s |
| 冻结覆盖净减少 | **16.60s** |
| 消除的原非FoG误报警 | 25.25s |
| 新增非FoG误报警 | 1.50s |
| 非FoG误报警净减少 | **23.75s** |

两模型都有事件重叠10/10，但冻结报警覆盖197.73→181.13秒，非FoG报警153.28→129.53秒。“事件碰到一次报警”掩盖了事件内空白，不能当100%准确率、一对一事件F1或提示成功率。

固定互斥分区把原始事件前3秒列为起始段、后3秒列为结束段，其余为内部；短事件优先归起始段。这只是描述规则，不是临床阈值。17.10秒丢失覆盖中，起始2.87秒、内部13.73秒（约80.3%）、结束0.50秒。不能只用修正起点延迟来解释全部损失，也不能未经重训内验证就把空白段填满。

弱窗口另有89个不同判断：32个原TP丢失、补回1个FN、消除53个FP、新增3个FP。它们属于窗口分母，与上述原始秒数/事件不混算。

## 四个固定案例

全部事件和记录均可回放，四张静态图按协议排序选择，而非人工挑好看片段。

| 案例 | 66维双踝 | 78维协调 | 含义 |
|---|---:|---:|---|
| P1/S1/T7，101.88s事件 | 覆盖76.20s / 74.8% | 67.70s / 66.4% | 净少8.50s，最长未报警片段4.5→12.0s |
| P12/S1/T1，2.70s事件 | 覆盖1.417s / 52.5% | 0.917s / 34.0% | 首次重叠延迟1.283→1.783s，即使都“检出”也漏掉大量事件时间 |
| P1/S1/T4，80.30–81.80s非FoG片段 | 报警 | 未报警 | 最长连续消除误报1.50s，不等于已识别主观停步 |
| P1/S1/T4，119.80–120.30s非FoG片段 | 未报警 | 报警 | 最长连续新增误报0.50s，负面案例同样展示 |

第一事件实际丢失9.0秒原报警、补回0.5秒，净少8.5秒；不能把净数当所有丢失时间。另一个P1/S1/T7的47.0秒事件覆盖43.50→38.88秒，两个长事件合计净少约13.12秒，占全队列净减少约79.0%。部分错误集中在长事件内部，不是整条事件完全漏掉。

## 可回放交付

本地打开`reports/a1_disagreement_v1_20261029/index.html`，无需网络即可读取内嵌数据。可选20条记录、10个真实事件或4个固定案例；支持播放/暂停、回到片段起点、键盘时间游标和20/60秒/整条记录视窗。同屏显示原始左右gyro模长、两模型分段概率及固定TRAIN阈值、原始FoG、两模型报警和未知时段。真实传感器模长仅绘图抽样到15Hz，所有统计仍使用60Hz。

浏览器实际核验了案例切换、播放/暂停、事件表“查看”跳转、视窗切换和键盘游标。页面是保存预测的离线审查，不是在线重新推理，也没有真人视频、实测落脚、提示响应、3D或疗效模拟。

输出包括`records.csv`（全部记录）、`events.csv`（全部事件）、`disagreement_segments.csv`、`window_disagreements.csv`、`selected_cases.json`、`summary.json`、自含回放页和四对PNG/SVG。源码为`src/fogguard/evaluation/a1_disagreement.py`、`src/fogguard/presentation/a1_disagreement_review.html`及两个audit/verify脚本。

```powershell
python -X utf8 scripts/audit_a1_disagreement.py --output-dir reports/a1_disagreement_reproduction
python -X utf8 scripts/verify_a1_disagreement.py --audit-dir reports/a1_disagreement_reproduction
```

需要同版raw和前轮锁定coordination实验。使用新目录，保留旧证据；不根据当前页面更改阈值并仍引用旧分数。原始数据、模型和生成目录不入Git。
