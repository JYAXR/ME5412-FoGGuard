# A1 泛化证据审查与后续测试选择

日期：2026-10-29。已保存 RF、SVM、HistGB、小型 CNN、姿态 ExtraTrees 及左踝备用 RF 等模型，目录中还有重复备份和不同特征版本。当前联合候选使用全量部署 ExtraTrees 主模型＋左踝 RF。保存模型不等于存在未使用的真实测试集。

## 已经如何测试

每次评价沿用五折按参与者留出的外层测试：每折 17/18 人训练、4/5 人测试，训练内部三折选参数，22 人各进入外层测试一次。例如第一折测试人为 2、10、13、14，拟合和内层选择均排除他们。前面报告的成绩来自这些 OOF 评分。

最终 model.joblib 则在全 22 人上重新拟合。不能拿同一批人的数据或它们的扰动，直接测试该全量文件后宣称对新参与者泛化。现有脚本保存了 OOF 和分折，通常没有保存各外层模型对象；做严格测试人扰动时，需要按保存规则重新拟合对应外层模型。

没有从项目开始就封存、从未参与方法选择的独立测试人群。外层每折拟合隔离仍成立，但研究者已反复查看这批外层结果并提出后续改进，组合候选也在组件结果出现后提出。现在重新从这 22 人抽 20% 不能恢复其“未被研究过”的状态。[scikit-learn 文档](https://scikit-learn.org/stable/modules/cross_validation.html) 解释了反复基于测试结果修改方法导致的评价偏差。

这些区间以已有模型的保存预测为条件，不重新训练，也没有校正反复查看外层结果带来的选择偏差。各折测试人和冻结分布不同，折间极值不等于单个患者性能范围。部分参与者没有冻结窗口，其 F1/Recall 的解释必须结合阳性数量。

## 合成步态能测什么

纯规则生成的正常步行、颤动、静止及转向可以检查程序行为、边界和演示，但冻结标签来自生成规则，不能单凭“看起来像真实波形”证明标签可信或新人群效果。项目现有 generate_demo_data.py 是 50Hz、单组 ax/ay/az/gx/gy/gz 合成 IMU；当前 FoG 模型要求 60Hz、左踝/腰背对应通道和原单位，不应将改列名或复制通道视为真实多传感器测试。

更有用的下一轮是用每折真正留出的原始记录做预先固定的传感器扰动，例如小幅噪声、安装方向变化、传感器偏置和连续缺测。扰动参数范围从训练人统计或明确工程假设确定；模型/阈值固定，不看扰动测试成绩继续调参；同一参与者及其全部扰动版本都留在测试侧，保留原始时间/标签，不能制造新的“真实冻结”。报告鲁棒性相对未扰动测试的下降、事件覆盖、误报和未知输入比例。

该测试回答的是对所设传感器变化是否敏感，不能取代独立真实人群测试。全新真实数据还需核对传感器位置、加速度/角速度通道、单位、采样率和标签定义；不能不经适配直接拿缺少角速度的数据评估现有完整模型。

建议顺序：固定当前候选 → 测每折留出记录的传感器扰动 → 单独保留完全合成场景作为工程测试 → 用未参与方法选择的新真实数据做最终验证。所有输出须明确标注这些不同证据来源。
