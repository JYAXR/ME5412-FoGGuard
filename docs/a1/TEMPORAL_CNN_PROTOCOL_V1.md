# A1 因果 CNN＋GRU：训练前固定协议

日期：2026-10-29。目标：判断连续步态历史是否能缓解上一轮CNN的漏检，并同时约束站立/转向误报。固定两组从零训练：`cnn_control`（同一公开CNN架构）与`cnn_gru`（相同卷积编码器、单向GRU32、Dense48）。不增加其他特征、增强或活动辅助头。本协议与配置先提交，再训练；结果不决定是否改配置或重新换人。

## 相同当前窗口，增加有限历史

继承14/4/4角色和gyro-only切窗：左踝三轴gyro，deg/s，60Hz、120点/2秒、步进30点/0.5秒，窗口内独立去均值，当前>=50%冻结为阳性。CNN只用当前片段；GRU输入按时间排列的三片段，结束时刻分别为当前之前4秒、2秒和当前，合计覆盖最近约6秒。利用三个不重叠片段降低重叠冗余，仍每0.5秒输出一次。

记录开头不等待六秒：只用已有1/2/3片段；显式lengths与packed sequence排除张量padding，padding不是填补缺测原始信号。遇记录键变化、gyro缺测或预测步长断档重置历史。无完整当前窗口就保持未知；不利用activity/fog真值选择历史或运行输出。窗口结束后才给出分数，不使用未来片段、不用双向GRU。

## TRAIN内部选择轮数与阈值，先锁模型再评价VALIDATION

沿用前轮TRAIN14内三折人员清单。对每个模型、每个外层折：

1. 只在该折拟合人员中，按“此人是否有冻结窗口”做一次stratified participant split，留3人做checkpoint、种子20261029+fold。外层留出人员不进入checkpoint、优化或归一化。
2. 共同固定训练设置：AdamW lr0.001/decay0.0004、BCE无类别权重、conv/Dense48 kernel L2 0.001、batch128、最多40轮、dropout0.4、patience6/min_delta0.001。该设置同时作用于两组；不同于上一轮lr0.008且直接用外部VALIDATION早停，所以主对照必须是本轮重训的CNN。
3. 内层选择epoch后，重新随机初始化，使用该折全部拟合人员训练固定轮数，再给外层留出人评分。每个TRAIN人只产生一份OOF，保存拟合/检查点/留出人员和全部历史链接。
4. 全部OOF只用于研发校准：沿用91点网格，按F1/BA/较高阈值选各组阈值。因为阈值见过OOF标签，其分数不能当独立测评。
5. 各模型取三个内层最佳epoch的中位数，在全部TRAIN14随机初始化并固定轮数拟合。模型和OOF阈值在MODEL_LOCK写入后才允许用独立评价脚本构造VALIDATION4窗口。VALIDATION不用于checkpoint/阈值/重新拟合。

VALIDATION已被过去研究使用，依然属于开发队列，不是盲测。TEST7/11/21/22本轮不构造新候选窗口或评分；不重新分人。当前原始窗口、输入支持相同，因此可以直接比较两组；另与既有作者CNN和RF参考做同窗口对照，注明训练/选择流程不同。

## 展示、判断与核验

保留VALIDATION全部20条原始记录及TRAIN全部70条，缺测无预测的事件仍计入分母。报告P/R/F1/AP、逐人/动作/任务、原始事件任意重叠、误报时长、冻结时间Recall、时间支持及条件延迟；当前窗口标签和窗口结束后报警时间语义分开。

预定研发成功条件：相同VALIDATION窗口中GRU比本轮CNN F1更高、误报时长不增加、冻结时间Recall不下降。任一失败如实报告；即使通过也不自动替换默认，不代表临床或外部泛化证明。

产物：两份TRAIN-only推理模型、内外层训练曲线/epoch与人员清单、OOF评分/阈值、模型锁、共同窗口比较、训练诊断与失败回放、PNG/SVG和HTML。源代码只新增本轮模块，不改变原模型/共享类型/控制器。独立核验原始窗口/历史时间、分组互斥、checkpoint来源、保存后评分、模型锁先于VALIDATION、流/批一致和真值/未来独立；完整项目检查。原始数据、模型、生成图和运行目录不进Git。
