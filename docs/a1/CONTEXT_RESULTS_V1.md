# A1 六秒因果上下文：实测结果 v1

日期：2026-10-28。方法见 [固定协议](CONTEXT_PROTOCOL_V1.md)，下游用法见 [A2 交接](CONTEXT_HANDOFF.md)。

结论：固定的历史摘要候选提高了窗口 F1、AUC 和 AP，减少了误报，但冻结召回、事件覆盖和条件延迟变差。保留为有进一步研究价值的候选，原默认模型不替换；不能宣布整体识别问题已经解决。

## 实现及公平比较

原二秒窗口 132 特征，加上二秒前、四秒前已完成窗口的 36 项运动摘要、当前减历史的差分和历史可用标志，合计 278 特征。仍为 RF 300 棵树、叶最小 2、balanced_subsample、seed5412；两组使用相同 RF 配置和默认特征抽样规则，特征数量变化也会改变每次分裂可抽取的特征数。

历史不读取活动或冻结标签，跨记录及断档重置。记录起点不足六秒时用明确的缺历史编码，仍在当前二秒窗口结束提供判定。没有整段双向滤波，没有未来样本，也没有为了提高指标删除开头窗口。批处理、保存加载、逐窗流与未来原始样本扰动测试通过。

两组均为 22 人、相同 95 条有效记录、9,636 个窗口；外层五折隔离参与者，内层三折以 FoG F1 优先选择阈值。普通 RF 的阈值、决定、窗口键和外层归属与上一轮完全相同，评分最大数值差为 2.22e-16，符合并行浮点求和误差量级，核验容差为 1e-12。

本轮队列此前已被分析，固定候选并不使它成为全新外部验证。未进行历史长度/参数搜索，也未依据外层结果继续降低阈值。

## 总体结果

| 指标 | 当前二秒 RF | 最长六秒上下文 RF |
|---|---:|---:|
| Precision | 0.5094 | 0.5534 |
| Recall | 0.7280 | 0.7016 |
| FoG F1 | 0.5994 | 0.6188 |
| ROC AUC | 0.8576 | 0.8691 |
| Average precision（AP） | 0.5622 | 0.6631 |
| TP / FP / FN / TN（窗口） | 1381 / 1330 / 516 / 6409 | 1331 / 1074 / 566 / 6665 |
| 真实事件有任意报警重叠 | 77 / 101 | 70 / 101 |
| 完全漏掉的真实事件 | 24 | 31 |
| 原始误报警事件 | 337 | 235 |
| 误报警时长（秒） | 678.67 | 556.17 |
| 时间 Precision | 0.4961 | 0.5357 |
| 时间 Recall | 0.6232 | 0.5985 |
| 新报警条件下延迟中位数（秒） | 0.8833 | 1.2833 |

窗口 F1 增加 0.0194；误报警事件减少 102 个，约 30.3%。但少检出 50 个冻结窗口，新增漏掉 7 个真实事件，没有新增覆盖的事件。新增漏掉的事件长 1.2–5.1 秒，均有完整模型时间支持，不能归因于缺测。

所有 106 条原始记录仍计入事件审计，包括 11 条无预测记录；两组均有 18 个事件完全没有模型支持。事件任意重叠不是一对一事件 F1。条件延迟仅统计已检出且没有预先报警的事件，分母分别为 58 和 55；更低的延迟或事件计数也不能直接证明最终提示效果。

AP 是整体精确率—召回率排序汇总，不是“66.31% 的临床成功率”；AP 改善也不抵消当前阈值下的漏检代价。

## 改善与失败发生在哪里

| 预先声明分组 | 窗口数 / 冻结窗口 | 当前二秒 F1 / Recall | 上下文 F1 / Recall |
|---|---:|---:|---:|
| 完整六秒历史 | 8876 / 1874 | 0.6190 / 0.7268 | 0.6247 / 0.7049 |
| 记录开头、历史不全 | 760 / 23 | 0.1836 / 0.8261 | 0.2740 / 0.4348 |

开头 760 个窗口全部保留；该组只有 23 个冻结窗口，候选从检出 19 个降到 10 个。完整历史组的 F1 提高幅度仅 0.0058。整体 F1 的改善不能直接解释为“有六秒历史就会显著更好”，也没有按分组切换模型。

22 人中，8 人 F1 提高、6 人下降、8 人相同；其中 7 人没有正窗口，F1=0 不表示他们的误报没有变化。重叠窗口不是独立患者，没有将窗口数量当成大样本做显著性结论。

按活动真值描述，站立 FP 从 471 降到 352，左右转 FP 从 407 降到 341；但左右转 FN 从 438 增到 490。活动标签仅用于事后分层，模型没有用它直接否决冻结，更没有完成转向意图预测。

## 验证和下一步

完整检查通过：279 项 pytest、Ruff、原基线审计、22×5 演示、112×5 工程比较及其独立核验、真实数据审计。本轮两组还分别经过原始 120 样本标签重建和全记录事件审计。独立保存产物核验检查了 9,636 行历史引用、相同内层人员、阈值规则和 60 个文件哈希；它不等于独立重新训练。

候选独立推理 CLI 产生 30 行 FoG-only 输出；9,636 行留出 runtime 接入现有事件管线，unsafe_input_windows=0。接口通过不能证明最终控制策略改善。方向仍为旧 OOF，没有新增临床、落脚、踏步响应或三维展示证据。

建议下一轮固定此特征定义，先在训练参与者内部以事件漏检和误报警共同约束阈值/确认规则，特别核查启动片段与左右转弯漏检。不要根据这批外层成绩直接挑更低阈值，也不要把 F1 升高当作自动替换默认的依据。要论证跨人泛化改善，还需未参与方法选择的数据；A2 可先使用已有 RF 接口开展自己的方向任务。

源码与说明仅提交本地贡献分支；模型、原始数据、整批输出未加入源码 Git，尚未推送或合并。
