# A1：训练内事件目标与确认规则 v1

日期 2026-10-28。冻结六秒上下文 278 特征和 RF 配置，只改变从评分到事件判定的选择目标。本轮是已多次分析队列上的探索，不是独立外部验证。原控制器、历史证据和默认事件集成器不变。

## 唯一预先固定的选择方法

外层仍隔离同一五折参与者。每个外层 TRAIN 集合内部以原三折生成未见该人的评分；只读取 TRAIN 人的原始逐点真值来选规则，TEST 人不得进入评分拟合、事件真值或参数选择。参数固定在 config/a1_event_v1.json，结果出现前保存输入/源码/配置哈希。

控制为相同六秒上下文 RF：在训练内选择窗口 FoG F1、balanced accuracy、较高阈值优先的 91 个 0.05–0.95 阈值，连续确认数为 1。候选在同一阈值网格、连续确认 1 或 2 中选择，合计 182 项。每次低分、不同记录或非半秒步进都清空连续计数；确认只能从当前窗口结束生效，不回填第一次高分时刻；没有新增退出保持或迟滞。

候选必须满足训练内误报警时长不超过控制的 110%，且真冻结报警时长不低于控制；可行项按检出原始事件数、真冻结报警时长、较少误报警时长、较少确认数、较高阈值排序。控制本身必定可行。110% 是固定工程容差，无临床达标含义，也不保证外层 TEST 会遵守此预算。

用误报警时长约束，避免仅按误报警事件数优化时，延长/合并报警反而让计数变好。事件仍以任意正重叠计为覆盖，不是一对一事件 F1，不表示事件起点准确。后续评价同时报告逐窗 P/R/F1、事件漏检、误报警事件、时间覆盖和条件延迟，保留所有结果。

## 原始时间与接口

每次决策从窗口结束起最多保持半秒，且截至下一决策或记录结束；只在有观测的逐点时间内计分。全 106 条原始记录、101 个真实事件都计入最终外层评价；无预测窗口的记录不当作模型阴性，不能从分母删除。训练选择也包含相应训练人的无预测记录事件。

is_fog 始终保留原始 score>=threshold 的定义，另存 event_fog 表示本轮连续确认后的判定。不能改评分使确认结果伪装成阈值输出。独立原始窗口审计使用 is_fog；event_fog 由另一条逐点事件审计与独立旧诊断函数核验。A2 若使用 event_fog，不能再套原集成器的默认二次确认及恢复迟滞并将成绩冒充本轮结果。

部署参数另在全队列三折参与者 OOF 内按相同目标选择，然后全量拟合一个模型。部署训练选择结果不是独立测试成绩。模型 CLI 仍提供原始评分，独立 EventGate 为每个输入流维护确认状态。运行输出不需要逐点真值或活动标签。

保存所有训练内候选、人员分折、预算及最终选择，外层只评价被选中的一套规则。展示方法流程、训练内可行候选、外层窗口与事件取舍、沿用上轮预先指定记录的留出回放。不得从外层遍历阈值挑更好结果。
