# A1 旋转不变表征对照：实际结果 v1

2026-10-29。**已重新训练并完成验证及Stanford研发复查。单独用10维旋转不变摘要替换原66维逐轴输入，没有改善整体检测，开发门槛失败，不采用替换。** 误报时间减少，但漏掉的冻结时间更多。代码可运行和旋转不变性成立，不等于准确率提高。

方法先锁定于 `c259e87`，训练/评分实现为 `43c0429`；见 [固定协议](INVARIANT_PROTOCOL_V1.md)、[推理及复现交接](INVARIANT_HANDOFF_V1.md)、[机器状态](invariant_status.json)。本轮由先前已查看的外部问题启发，是研发；源VALIDATION与Stanford都不是新盲测。没有新模型TEST分数，没有目标训练、校准、旋转试分或按结果追加候选。

## 实际实现了什么

两种表征分别重新训练随机森林：300棵、叶最少2点、balanced_subsample、seed 5412；沿用TRAIN14三个人员隔离折、完整双踝120点/60Hz窗口及30点步进。每种表征保存三个折模型和一个最终TRAIN模型，共八个文件。66维对照重新训练后复现了旧OOF和VALIDATION的概率及判断。

候选逐踝计算三轴合成RMS、三轴频带功率和、冻结/步态功率比、步态带峰频，共10维，直接沿用此前独立核验的定义。没有幅度归一化、新损失、历史、缩窗、增广或后处理。独立转动左右踝的坐标轴不会改变这些表征；幅度、佩戴位置、左右身份和标注差异仍可能影响结果。

这是“66维逐轴统计→10维摘要”的整体替换，会同时压缩信息。RF的max_features政策保持sqrt，但实际每节点候选数从8变3；没有另行调参。因此不能把好坏完全归因于“取消轴方向”。

## 展示、核验与决定

本地数据/模型：`reports/a1_invariant_v1_20261029/`。本地说明页：`reports/a1_invariant_presentation_v1r1_20261029/index.html`，提供七组PNG/SVG：实现流程、两来源同窗指标、原生时间取舍、外部全部参与者、TRAIN阈值选择、固定P6与P7案例。r1更新核验元数据，明确区分候选重评分10033行和旧对照核对10033行；模型/评分/图形内容不变。

独立核验包括：2014个VALIDATION窗口的10项逐轴滤波/FFT公式；复用上一轮独立重算并有哈希锁的6383 TRAIN/10033外部摘要；原始窗口网格/真值、六折模型重载评分、人员隔离及TRAIN阈值复算、两种源VALIDATION与外部概率、422条原生事件行及时间积分、旧66维复现、无真值运行字段。核验不是独立重新训练。

368项测试（包含recognition）、Ruff、完整项目及原始真实数据审计通过，七组图另做视觉检查。原始模型、数据、锁和历史结果未覆盖，默认检测器与A2/控制器不变；代码/聚合说明本地提交，未推送/评审。

**本轮决定：保留原66维双踝基线，拒绝10维整体替换。** 这一结果只否定当前压缩方案，不能否定所有旋转不变模型。若继续，下一项应保留原66维，再单独追加这10项摘要，检验是否有增量信息；不要同时修改窗口和阈值目标。Stanford已经参与研发，最终泛化结论仍需另一个未参与开发的来源。
