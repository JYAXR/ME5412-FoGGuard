# A1 因果 CNN＋GRU 对照：结果 v1

日期：2026-10-29。已完成同gyro输入的CNN与CNN＋GRU、TRAIN内部按人选轮数/阈值、锁定后VALIDATION评价、独立审计、流式接口与六张展示图。**GRU比本轮重训CNN检出更好，但误报时长增加17.7%，未达到预定升级条件；也未超过前轮CNN和既有RF的验证F1。默认模型不替换。**

本轮没有构造或评分新候选TEST；VALIDATION是已有开发队列，不是新的盲测。方法见 [预先固定协议](TEMPORAL_CNN_PROTOCOL_V1.md)，使用见 [交接](TEMPORAL_CNN_HANDOFF_V1.md)。协议c57717d与实现15ab14b均在训练前提交，未按新结果调整epoch、阈值或种子。

## 实现与数据来源

保留左踝gyro三轴、60Hz、120点/2秒、每30点/0.5秒滑动，窗口>=50%为FoG；每个完成窗口独立去均值，不插值、不以活动真值过滤输入。两组当前窗口完全相同：TRAIN14有6655窗口，VALIDATION4有2014窗口、470阳性，20条原始记录、10个冻结事件。

- `cnn_control`：同前轮公开CNN架构，共8353参数，仅当前2秒。
- `cnn_gru`：相同四层卷积与GAP24编码，单向GRU32、Dense48/Dropout0.4、一个FoG输出，共14305参数。依次使用结束于当前前4秒、前2秒和当前的三个不重叠片段，覆盖约6秒；缺历史时只用1/2个真实片段，无额外六秒启动等待。padding排除在编码和packed GRU之外，不是补齐缺测原始信号。

记录/gyro缺测/步长断档重置历史，输出从窗口结束才可用；没有双向GRU或未来信息。新增每流独立缓冲，批量与逐窗推理一致性按float32允许1e-6；原始采样缓冲由调用方提供，不把任意分块当整段。

本轮比较的是整套CNN与CNN＋GRU架构，后者参数也更多；未做“同参数、只给当前片段GRU”的消融，不能把差值完全归因于过去4秒历史。

## 先在TRAIN内部选，再锁定

三个外层人员折继承前轮TRAIN14诊断清单。每折只从拟合人中固定抽3人做checkpoint，外层留出人不参加任何轮数选择。共同配置为AdamW lr0.001/decay0.0004、BCE无类别权重、kernel L2 0.001、batch128、最多40轮、patience6/min_delta0.001。内层选轮数后重新初始化，在全部外层拟合人上训练该轮数再产生OOF。

| 模型 | 三折内层最佳epoch | 最终中位epoch | TRAIN-OOF阈值 | OOF校准F1 |
|---|---|---:|---:|---:|
| CNN | 16 / 15 / 13 | 15 | 0.39 | 0.5478 |
| CNN＋GRU | 14 / 2 / 3 | 3 | 0.39 | 0.5737 |

阈值仍为91点F1/BA/较高阈值目标，但只用TRAIN的OOF。该F1参与阈值选择，不能当独立测试。最终模型从零在全部TRAIN14拟合，epoch取三折中位数，不沿用某折权重。两模型的epoch/阈值/文件在MODEL_LOCK写入之后，另进程才提取VALIDATION；未因GRU只选到3轮而事后延长训练。

前轮作者CNN采用lr0.008且用VALIDATION选checkpoint和阈值，本轮改变选择流程与共同优化设置。因此主对照是本轮重训CNN，历史CNN仅作参考，不把与前轮的差值当单因素实验。

## 同2014个验证窗口的主对照

| 指标 | 本轮CNN | 本轮CNN＋GRU |
|---|---:|---:|
| Precision | 0.6041 | 0.6367 |
| Recall | 0.5000 | 0.6787 |
| F1 | 0.5471 | 0.6571 |
| AP | 0.6238 | 0.6829 |
| TP / FP / FN | 235 / 154 / 235 | 319 / 182 / 151 |
| 原始事件任意报警重叠 | 8/10 | 9/10 |
| 冻结时间Recall | 0.4680 | 0.6446 |
| 报警时间Precision | 0.5672 | 0.6053 |
| 误报警时长 | 83.55s | 98.35s |
| 原始误报警片段 | 55 | 40 |
| 条件新报警中位延迟 | 1.283s | 1.983s |
| 时间支持 | 0.9372 | 0.9372 |

GRU窗口F1高0.1099，TP增加84、FN减少84，但FP增加28；误报时长增加14.8秒（17.7%）。虽然原始误报片段数减少，误报持续时间更长，不能只挑40 vs 55说误报更少。条件延迟排除完全未覆盖事件，且两组被覆盖事件集合不同，不是可直接归因的同事件硬件延迟比较。

预定研发条件为F1更高、误报时长不增加、冻结时间Recall不下降：前者和最后者通过，误报时长条件失败。因此总体FAIL，不通过修改阈值或放宽条件把它变为PASS。

## 历史参考与逐人/动作边界

历史CNN在同2014窗口为P0.6715/R0.6830/F1 0.6772、误报警82.23s、事件8/10。GRU多覆盖一事件，但F1更低、误报时间更多。原左踝RF在同窗口F1为0.6912、事件10/10、误报警166.88s；它用acc+gyro及历史，传感器信息不同。

五模型共同1921窗口、389阳性：

| 模型 | Precision | Recall | F1 |
|---|---:|---:|---:|
| 本轮CNN | 0.5511 | 0.4576 | 0.5000 |
| 本轮CNN＋GRU | 0.5777 | 0.6118 | 0.5943 |
| 前轮作者CNN | 0.6259 | 0.6452 | 0.6354 |
| 原六秒RF | 0.5467 | 0.8123 | 0.6536 |
| 原左踝RF | 0.5151 | 0.8766 | 0.6489 |

所以不能用GRU的全池0.6571与六秒RF不同窗口池的0.6536直接宣布GRU更好。共同窗口下，GRU仍低于三个历史参考。

验证动作分组（仅事后真值分析）：

| 非FoG活动 | 负例窗口 | CNN FP | GRU FP |
|---|---:|---:|---:|
| 站立 | 285 | 77 | 83 |
| 右转 | 176 | 25 | 37 |
| 左转 | 200 | 28 | 26 |
| 行走 | 629 | 5 | 2 |
| 站到坐 | 49 | 8 | 22 |

GRU左转阳性检出80→133/168，右转152→183/298，但站立/右转/站到坐误报并未解决；该验证集只有1个站立FoG阳性，GRU漏掉，不能据此泛化到全部站立冻结。Stand不等同主观主动停步，不能用真值活动直接否决FoG。

逐人GRU F1：P1 0.7148、P5 0.5455、P12 0.6323；P10无阳性，513个窗口仍FP37个，不能将其零F1解释为未检出冻结。三个内层epoch14/2/3的差异提示人员变化下的训练选择不稳定，但不能单凭本实验断言原因。

固定回放沿用上一轮预先选择的P12/S1/T4失败记录。GRU覆盖了此前作者CNN漏掉的4.9秒事件，约2.28秒后报警；但之后仍有长段误报。另一2.7秒事件仍未检出，10个原始事件都有至少部分支持，不能归咎于输入完全缺失。9/10为任意重叠，不是准确率或一对一事件F1。
