各组都用左踝三轴gyro、60Hz、120点/2秒、步进0.5秒；窗口内去均值，按前4秒/前2秒/当前三个片段经相同CNN-GRU32编码。缺历史只用已有片段，记录/gyro缺测/断档重置，不补缺失原始信号。当前窗口>=50%为FoG目标。第一条输出仍从当前2秒结束提供。

共同AdamW lr0.001/decay0.0004、kernel L2 0.001、batch128、dropout0.4、最多40轮、patience6/min_delta0.001。保留内层选epoch→随机重新初始化→全外层拟合人固定epoch产生OOF→三个内层epoch中位数决定最终TRAIN14拟合。各组都用**未加权FoG BCE＋相同kernel L2**作为checkpoint目标，不纳入参与者权重或辅助loss；同样用TRAIN的OOF网格F1/BA/较高阈值决定阈值。

## 两个独立改动

1. **参与者均衡**：每个实际拟合子集独立统计人数P和各人窗口n_p，总窗口N；每窗权重N/(P*n_p)，均值1、每人权重总和N/P。只加权训练FoG BCE，其他流程相同。没有类别平衡、困难负样本挖掘、重采样、权重裁剪或按验证分数设权重。
2. **活动辅助**：均匀FoG BCE加0.2倍活动交叉熵。只把当前窗口TRAIN活动多数标签1..7映射为0..6；0/混合忽略，不重标为正常。辅助标签不作为特征、历史选择或运行门控；checkpoint仅消费FoG，不使用其活动标注。站立可同时为FoG，禁止“站立即正常”否决。

验证图表里的真值活动只是事后分析。运行模型只消费传感器并输出二元FoG分数/阈值/判定，不要求activity/fog标签，也不把辅助输出宣称为提前转向意图或迈步成功。
