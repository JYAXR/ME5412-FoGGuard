# A1 首轮实验：近期运动与窗口内变化

本文件说明已固定的实验方法。结果另存，不用结果倒推修改方法。

## 本轮要回答的问题

当前分类器把一个已完成的两秒 IMU 窗口概括为统计特征。我们检验：保留原有两秒特征，加入最近一秒的运动幅度及前后变化，能否改善冻结窗口的区分和边界表现？

这是一项明确的特征实验，不预先宣称有效，也不将多尺度特征本身称为新的通用研究方法。项目创新需要进一步结合 A2 的方向任务和后续反馈决策，并有对照证据。

## 数据与任务固定项

- FoG-STAR v3，左踝与腰背 12 个通道，60 Hz。
- 120 个样本形成两秒窗口，每 30 个样本移动一次；窗口不跨受试者、会话、任务或长断档。
- 窗口中至少 50% 样本标注 FoG 时，窗口真值为阳性。
- 输出可用时间为窗口最后一个采样点；不回填窗口起点。
- 本轮禁用短缺失插值；已核查本数据原流程实际填补的短缺失数为零，再逐窗验证与历史 OOF 的 9,636 个窗口对齐。
- 保留全部 106 条原始记录的覆盖口径，模型支持记录仍为 95 条。

## 两种特征

基线：沿用旧函数计算 156 个特征，去掉每通道 raw_mean/raw_median，剩 132 个。

候选：在 132 个特征后，每通道加入 5 个特征，共 192 个。沿用原两秒窗口的 0.5–20 Hz 滤波结果，将其分为前 60 点 p 和后 60 点 r：

1. recent_std = std(r)，标准差的 ddof=0。
2. recent_rms = sqrt(mean(r²))。
3. recent_range = max(r) − min(r)。
4. recent_mean_abs_diff = mean(abs(diff(r)))。
5. rms_recent_minus_previous = sqrt(mean(r²)) − sqrt(mean(p²))。

前后两段是完整两秒滤波结果上的统计，均在整个窗口结束后可用。不能把前半段特征解释为更早一秒已获得的独立实时结果。第一轮不增加短窗频带能量，避免混入频率分辨率/能量尺度变化。

代码：src/fogguard/modeling/a1_fog.py。a1_features 负责单窗，a1_matrix 负责一致的批量特征，A1FogModel 保存和复用同一套特征规则。

## 模型与阈值

两组均为 300 棵随机森林，min_samples_leaf=2、balanced_subsample、seed=5412。

外层直接读取前置基线报告中已冻结的五折受试者划分。对每个外层训练集，在其内部再做三折 StratifiedGroupKFold，生成仅来自未见内层参与者的分数。阈值从 0.05–0.95 共 91 个值中选择，优先 balanced accuracy，其次 macro-F1，最后较高阈值。

固定阈值后用外层全部训练参与者重训，再预测外层测试参与者。每个窗口只获得一次外层测试预测。fold_audit.json 保存所有内外层受试者列表和每个阈值的训练内验证成绩。

历史 OOB 模型仅作为参考。用于判断特征价值的是“原特征+分组内层阈值”和“新特征+同一分组内层阈值”的比较。外层测试标签不参与阈值选择。

全量模型另行拟合，部署阈值使用五个外层训练阈值的中位数，不用它替换 OOF 每折阈值。全量模型处理原数据的输出不作为留出成绩。

## 评价与展示

- 窗口：precision、recall、FoG F1、macro-F1、AUC、混淆矩阵。
- 事件：沿用独立核验器的全部原始真值事件、报警重叠、时间覆盖、误报事件和新报警延迟。事件有重叠不是一对一事件 F1。
- 分组：逐人、活动、任务与真值表现组。没有阳性样本的组，召回/F1 必须结合阳性数量解释，不当作“未检出患者”。
- 固定案例：沿用前置审计中最长 TP/FP/FN 段，不根据本轮新模型挑图。
- 过程图：原始信号、近期 RMS/变化、三组模型分数与判定、原始标签同轴显示。
- 本数据和测试参与者已在项目中被分析过，因此结果属于既有公开数据上的后续工程实验，不是未触碰的独立外部验证。

本轮只跑一个预声明候选，不以外层结果反复调参。无论改善、持平或退步均交付，不自动替换原共享模型。

## 运行

先准备项目依赖与 requirements-readiness.txt。已有前置包时：

```powershell
python -X utf8 scripts/run_a1_experiment.py --baseline-dir reports/readiness_20261028_verified
```

首次没有前置包时，先运行 run_algorithm_readiness.py 并将其输出目录传给 --baseline-dir。脚本只接受新输出目录，规则与源码哈希先写入 protocol.json，再进行训练。

## 给 A2 的边界

A1 提供冻结候选模型，不改控制器或共享 types.py/interfaces.py。a2_runtime.csv 是留出输出且不含 truth_*，其中方向为未改动的历史基线 OOF；A2 继续开发方向/转向意图任务。评价标签在 evaluation_truth.csv 单独保存。

新数据推理使用 scripts/predict_a1_fog.py 和本轮 model.joblib，输出只有 FoG，不补造方向、主观意图或步响应。A2 应按记录键和窗口时间合并自己的方向结果，再接现有事件/控制适配层。
