## 标签与事件的时间机会

逐原始事件统计所有实际决策保持区间的重叠。分别计算：原模型的报警；把既有窗口弱标签当决策的“标签规则参考”；单个事件自身占输入120点>=60点的窗口是否在该事件仍发生时可用。保留窗口末端+1/6秒的真实可用时刻和最多0.5秒保持，不回填起点。

“标签规则参考”用事后真值构造，绝非可部署算法；其覆盖不是性能上限，因为真实分类器可以在弱标签0的窗口报FoG。单个事件占比与整窗所有FoG占比可能不同（相邻事件可合并占比）。统计无机会/有机会仍漏检、事件内最高既有分数、纯FoG/混合窗口分数；不搜索阈值或报告调阈值后的新成绩。
