# A1 连续事件分歧审查范围 v1

2026-10-29。本轮只读既有coordination v1锁定结果，不重新训练、改阈值、选择默认或构造新模型TEST。使用全部VALIDATION4的20条原始记录及全部10个FoG事件；该队列已经用于开发，不能称新泛化验证。

1. 逐原始60Hz采样格重建真值和模型决策。预测仅在窗口末端起效，最多保持0.5秒/下个决策；未知时段保留未知。禁止插值概率跨越缺口或回填窗口开头。
2. 同时保留弱窗口标签分歧和原始时间分歧，不能混合两种分母。按记录与连续FoG事件报告支持、报警覆盖比例、首个重叠延迟、最长未报警连续片段，分解“原报警丢失/新增覆盖”。在非FoG段分解“原误报被移除/新增误报”。
3. 原始事件内把前3秒称起始段、后3秒称结束段，其余称内部；短事件优先分配给起始段，分段互斥。只是固定描述分区，不是临床阈值或新训练目标。
4. 全部事件和记录可回放。静态展示固定选择：损失FoG报警时间最多的事件；原始覆盖比例下降最大的另一事件；消除非FoG误报时间最长的连续片段；新增非FoG误报最长的连续片段。并列按记录键/时间，找不到则明确NOT_AVAILABLE，不重挑好看案例。
5. 回放同屏展示原始gyro模长（仅绘图抽样至15Hz）、真值、两模型分段概率/固定阈值、实际决策区间。计算不抽样；未知时段明确。无真人视频、实测落脚、3D人物、提示/响应或临床效果。
6. 核对事件表与已保存event_coverage、聚合时间与EventSupport/旧comparison，保留全部记录；独立复算连续片段/分区和数据/锁/源码哈希。模型不重评分，本轮不新增预测成绩。
7. 外部数据只做公开原始资料/文件schema与可用性核对。本轮不以相似格式冒充输入兼容，也不以未跑外部数据声称通过。传感器缺失不能用另一位置/加速度或复制通道顶替gyro；单位、采样、轴系、记录边界与标签映射必须先固定且不看目标成绩。
