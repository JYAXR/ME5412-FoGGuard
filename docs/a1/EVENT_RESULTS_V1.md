# A1 事件目标与确认规则：结果 v1

开始于 2026-10-28，完成核验于 2026-10-29。方法见 [固定协议](EVENT_PROTOCOL_V1.md)，使用见 [A2 交接](EVENT_HANDOFF.md)。

结论：候选多覆盖 1 个冻结事件，冻结时间覆盖上升，但误报警时长增加 14.5%、窗口 F1 下降。训练内预算未能在外层保持，收益不足以支持替换默认方案；保留完整失败边界，不继续根据本批外层结果放宽预算或挑阈值。

## 这次改了什么

六秒上下文 278 特征和 RF 保持不变，两组使用完全相同的外层评分。控制在训练参与者内按窗口 F1 选阈值，单次高分确认；候选在训练内比较 91 个阈值和连续 1/2 次确认的 182 套规则，以原始冻结事件覆盖优先，同时限制误报警时长不超过控制的 110%、真冻结报警时间不下降。

五折外层参与者与训练内三折均隔离；原始逐点事件选择只读取 TRAIN 人，包括其无预测记录。没有拿外层测试人的事件重新选规则。全队列部署参数另用三折参与者 OOF 选择，不把部署训练回放当外层成绩。

连续确认输出单独保存在 event_fog，is_fog 仍表示 score>=threshold。二次确认不会回填第一次高分；低分、记录变化、半秒步进断档均重置，没有新增退出保持。原有默认事件集成器没有替换。

## 外层结果

所有 9,636 个有效窗口及 106 条原始记录计入对应评价；101 个冻结事件中，83 个有模型时间支持，18 个完全无支持。事件任意重叠不是一对一事件 F1。

| 指标 | 六秒上下文控制 | 训练内事件目标候选 |
|---|---:|---:|
| 真实冻结事件有报警重叠 | 70 / 101 | 71 / 101 |
| 有支持但完全漏掉的事件 | 13 | 12 |
| 误报警事件 | 235 | 238 |
| 误报警时长（秒） | 556.17 | 636.82 |
| 真冻结报警时长（秒） | 641.62 | 656.27 |
| 时间 Precision | 0.5357 | 0.5075 |
| 时间 Recall | 0.5985 | 0.6121 |
| 事件判定逐窗 Precision | 0.5534 | 0.5245 |
| 事件判定逐窗 Recall | 0.7016 | 0.7180 |
| 事件判定逐窗 FoG F1 | 0.6188 | 0.6061 |
| 新报警条件下延迟中位数（秒） | 1.2833 | 1.1333 |

新增覆盖 1 个事件，没有丢掉原控制已覆盖事件。代价是多 80.65 秒误报警；误报警事件数只多 3 个，说明不能仅凭次数判断误报负担。测试误报警时长为控制的约 114.5%，超出训练选择的 110% 容差；预算是训练内筛选条件，不能作为跨人保证。

条件延迟的分母分别为 55 和 54，不包括漏掉或已经预先报警的事件，不能写成全体冻结的平均检测延迟。窗口指标针对 event_fog；候选原始 is_fog 的 F1 为 0.5978，单独保存在 recognition/，不可将两个口径混用。

两组评分完全相同，AUC=0.8691、AP=0.6631 没有提高。变化来自阈值与确认规则，不是 RF 获得了更强的排序能力。该队列此前被反复分析，本轮仍是探索；未证明新队列泛化或患者提示效果。

## 展示与验证

独立核验通过：五折人员隔离与参数分配、每次选择完整 182 套规则、预算与排序、12 次训练控制/候选的旧逐点区间算法复核、两组各 9,636 行因果重放与全 106 条原始记录事件积分、65 个文件哈希。核验的是保存评分和事件运算，没有独立重新训练。独立传感器推理 CLI 产生 30 行无 truth_* 的评分/event_fog 输出。

完整交付检查通过：288 项 pytest、Ruff、原基线审计、22×5 演示、112×5 工程比较及独立核验、真实数据审计。原控制器和历史证据保持原样。
