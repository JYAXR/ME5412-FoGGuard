# A1 困难负样本加权：实测结果 v1

日期：2026-10-28。方法见 [固定协议](HARD_NEGATIVE_PROTOCOL_V1.md)，接口见 [A2 交接](HARD_NEGATIVE_HANDOFF.md)。结论：本轮固定候选未改善识别，保留原默认模型；没有根据外层成绩继续调整加权倍率或挖掘阈值。

## 做了什么

在原 132 个特征、300 棵树 RF 和同一批 9,636 个窗口上，对照普通 RF 与困难纯负样本加权 RF。窗口内完全没有 FoG，且训练内两折参与者留出分数至少 0.30 的样本，额外训练权重设为 2；其他窗口保持 1。活动真值仅用于描述，不参与挖掘或运行时否决。

五折外层参与者留出、三折内层阈值选择、两折训练内困难样本挖掘分别隔离。每次内层拟合重新挖掘，不能借用可能见过当前外层测试人的历史 OOF。阈值统一按内层 FoG F1、balanced accuracy、较高阈值排序选择。基线复现上一轮同规则 RF 数值。

这是同一已分析队列上的探索性比较，并非全新外部验证，也没有证明患者使用效果。

## 训练内诊断

第一外层折的 7,308 个训练窗口中，有 582 个高分纯负窗口、1,255 个 FoG 窗口、221 个混合负窗口。该诊断排除本折测试参与者，不合并成全队列独立检验。

| 指标中位数 | 高分纯负 | FoG |
|---|---:|---:|
| 踝部动态加速度 RMS（g） | 0.2035 | 0.2275 |
| 躯干角速度向量 RMS（deg/s） | 12.2392 | 12.8120 |
| 踝部高/低频能量比 | 1.6810 | 1.5275 |

所选特征分布明显重叠，简单通过运动幅度排除冻结缺乏依据。这不证明其他特征或更长时序一定无法区分。高分纯负窗口活动计数为：Walk 53、Sit 40、Stand 198、SitToStand 50、StandToSit 24、RightTurn 87、LeftTurn 108、mixed 20、unclassified 2。重叠窗口不等于独立患者样本。

## 留出结果

| 指标 | 普通 RF | 加权 RF |
|---|---:|---:|
| Precision | 0.5094 | 0.4881 |
| Recall | 0.7280 | 0.7122 |
| FoG F1 | 0.5994 | 0.5792 |
| ROC AUC | 0.8576 | 0.8546 |
| Average precision | 0.5622 | 0.5523 |
| TP / FP / FN / TN（窗口） | 1381 / 1330 / 516 / 6409 | 1351 / 1417 / 546 / 6322 |
| 真实事件有任意报警重叠 | 77 / 101 | 77 / 101 |
| 原始误报警事件 | 337 | 352 |
| 时间 Precision / Recall | 0.4961 / 0.6232 | 0.4741 / 0.6085 |
| 新报警条件下延迟中位数（秒） | 0.8833 | 0.9833 |

事件统计覆盖全部 106 条原始记录，其中 95 条有有效窗口；两者均有 18 个真实事件没有模型时间支持。事件任意重叠率不是一对一事件 F1。延迟只统计已检出且非预先报警的事件，两组分母分别为 58 和 59，不能作为全部冻结的平均延迟。

加权后的 Precision、Recall 和排序指标均下降，不能因为真实事件覆盖数相同而宣布改进。改变训练权重没有增加新的区分信息；本轮结果只否定这一固定候选，不否定所有困难负样本方法。

## 验证与后续

完整交付检查通过：269 项 pytest、Ruff、原基线核验、演示和工程比较、真实数据审计。独立保存产物核验通过三层参与者隔离、阈值选择、38,544 行跨五个外层训练集合的权重规则、65 个文件哈希；38,544 行包含重复训练使用，不是独立窗口数。该核验没有独立重新训练。

候选独立预测 CLI 产生 30 行 FoG-only 输出；9,636 行 runtime 接入原事件管线，事件阶段及集成原因均无缺失。这仅说明接口可用。方向仍为旧方向 OOF，本轮没有训练 A2 转向意图模型。

下一轮研究应先在训练参与者内部审查冻结启动/恢复边界和更长的因果运动上下文，再冻结一个有新增区分信息的假设。当前外层队列已经反复查看，应明确探索性质；如要声称泛化改善，需要未参与方法选择的参与者或外部数据。现阶段可以将保留的 RF 接口与失败边界交给 A2，不必等待这一候选变好。
