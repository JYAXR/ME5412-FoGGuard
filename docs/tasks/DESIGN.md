# 工业设计：PPT 与最终展示

## 目标

用易懂的画面与汇报材料呈现 FoGGuard 的问题、算法判断、提示切换及结果。A1/A2/B1/B2 提供代码、指标与过程材料，工业设计负责最终表达。

## 输入

- A1 三模型实现与比较图表。
- A2 原始信号、冻结/方向结果及时间线。
- B1 运动反馈、状态切换原因与脚印/声音命令。
- B2 验收结果、失败案例、来源说明和保存的展示包。

## 工作内容

1. 先完成统一视觉风格和 PPT 结构，再接入已验收的图表与数据。
2. 最终可视化展示行走、左右转、冻结、前进提示、原地踱步和退出。
3. 用同一保存时间线驱动画面、脚印、声音和状态说明，播放器不重新判断冻结或切换策略。
4. 显示真实数据、模型判定、运动代理和模拟响应的来源。人物和脚印的示意位置不能标为实测位置。
5. 生成现场演示、备用视频及静态截图，核对字幕和 PPT 指标一致。

## 建议汇报结构

问题与目标、系统设定、A1 三模型与结果、A2 方向、B1 反馈/策略、B2 联合结果、最终演示和能力边界。尚未验收的结果保留待补，不填入推测数字。

## 完成条件

观众能看懂为什么提示、为什么切换以及结果从哪里来；所有成绩能回到 B2 的保存结果；现场不能运行时有同版备用视频。最终 3D 和视频制作属于本角色，算法成员交付对应输入与技术支持。
