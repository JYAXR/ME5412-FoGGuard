A 组的感知算法、独立测试和统一展示已交付到 `main`。现在可以开始组织 PPT、统一画面风格及回放界面，无需等待新的 A 组训练。

| 材料 | 入口与用途 |
|---|---|
| 统一英文图表页 | [打开 A 组展示](../a_group_showcase/index.html)：方法流程、数据范围、冻结、方向、融合与联合时间线 |
| 图片与数据索引 | [FIGURE_CATALOG.csv](../a_group_showcase/FIGURE_CATALOG.csv)：7 张 PNG/SVG 图的图注及数据映射 |
| 汇总数据 | [all_metrics.csv](../a_group_showcase/data/all_metrics.csv)、[方法规格](../a_group_showcase/data/methods.csv)，供图形编辑和表格排版 |
| 正式感知成绩 | [固定 TEST 报告](../a_group/README.md)，给出分母、误报漏检、原始与融合成绩 |
| 回放基础 | `presentation/`、`ui/`，现有工程页面可用于界面开发参考 |
| 后续最终运行包 | B2 交付的感知、反馈、命令、配置、来源及案例说明，目前待完成 |

当前统一页是图表与数据素材，不是最终 PPT 或完整 3D 演示。原 SVG/PNG 和来源清单保持不变，设计稿作为新的产物保存。

## 分步任务

| 任务 | 工作 | 交付物 | 完成条件 |
|---|---|---|---|
| D-01 PPT 主线与视觉规范（现在开始） | 用已交付 A 组素材安排问题、方法、测试、限制和过程；预留反馈/策略/联合结果页面 | PPT 结构、配色/图例/术语规范、A 组已完成页面 | 数字可回溯，开发与 TEST 不混用，原始与融合成绩分开 |
| D-02 回放界面准备（可并行） | 设计人物/地面、脚印、声音状态、状态原因及来源标识；约定 B2 包的读取方式 | 界面原型、字段对照、场景脚本 | 不在界面中重新分类或决定切换；预设位置标明示意 |
| D-03 接入正式保存包（依赖 B2） | 用同一保存命令驱动画面、脚印、声音和字幕 | 最终可视化及关键帧截图 | 时钟、命令 ID、启停及模式变化与 CSV 一致 |

## 建议汇报顺序

问题和目标 → 系统设计 → A 组方法与 TEST 结果 → B1 反馈和提示策略 → B2 联合验证 → 最终演示与限制。B1/B2 未交付前的页面标为待补，不填推测数字。

画面需能解释行走/左右转、冻结判断、前进提示、有效无响应、原地交替踱步、返回前进及退出。真实模型判断、代理反馈和模拟响应采用明确标识；人物和脚印的示意位置不能称为实测足部位置。

## 数字与图表口径

- 正式效果使用统一页的 TEST 数据；开发验证仅用于解释方法选择，放在明确标注的补充部分。
- 冻结指标基于 1,605 个共同支持窗口；方向主指标基于 676 个有效且方向明确的窗口，不能省略分母或把拒识排除后当总体准确率。
- 原始方向准确率 81.07%；融合后为 51.78%、覆盖率 54.73%，两个阶段需要分别展示。原始模型分数不能代替下游融合效果。
- 现有测试时间线保留误报和未知状态。提前转向预测不是可用能力；`recovery` 不是实测迈步成功；模拟策略不作为患者疗效。

## 接收 B2 包时核对

逐项核对 `perception_runtime.csv / feedback_runtime.csv / commands.csv` 的时钟、字段及来源，按清单播放。缺少声音或人物动画的实际条件时，界面显示保存的参数/状态并注明表达方式，不虚构传感器证据。最终材料由工业设计负责制作，算法成员提供对应输入与技术说明。
