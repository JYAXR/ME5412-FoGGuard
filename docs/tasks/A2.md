## 后续维护工作

1. 向 B1/B2 解释 `available_at_s` 决策时间、`window_end_s` 兼容别名与各来源原始输入范围，确保接收方不回填预测。
2. 协助处理可复现的字段/安装/来源问题。计时行、另一来源的更新和保持值均不是新增观测；未知方向不应强行填成直走。
3. 维护模型包、配置、版本及运行说明。权重单独传递，日期证据、独立测试和统一展示包保持可追溯。

接收方的来源/时间/缺测检查列入 B2 的接入任务；A2 按具体问题提供支持。实时时延测量属于将来在线部署的单独验证项，不阻止本轮离线算法交付完成。

## 已记录的结果与限制

原始方向在 676 个有效且目标明确的 TEST 窗口上准确率 81.07%、macro-F1 0.844；固定融合后准确率 51.78%、覆盖率 54.73%。融合的拒识和延迟不能用原始模型分数掩盖。冻结事件的 `recovery` 仅为模型状态，不是实际迈步完成。

提前转向预测已完成可行性研究，效果未达到可用水平，当前流程只使用 `direction_task=current / horizon_s=0`。本轮无新增训练、提前预测攻关或测试阈值选择任务；新算法迭代需另定开发与独立评价方案。
