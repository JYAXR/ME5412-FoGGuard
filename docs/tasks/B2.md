# B2：联合验证与最终展示数据包

## 当前状态与目标

A1/A2 的模型、感知适配、固定独立测试和统一图表已交付到 `main`。B2 从现有感知输出开始复核接口，可与 B1 的运动反馈开发并行；随后接入 B1，完成同输入策略对照和最终保存数据包。

现有 `evaluation/`、`recognition/`、`run_engineering_comparison.py` 和 `verify_engineering_comparison.py` 提供评价及生命周期检查基础。`run_complete_demo.py` 使用构造候选与模拟响应，不代表正式真实反馈闭环。

| 输入 | 使用方式 |

| [A 组固定测试](../a_group/README.md) | 引用既有模型成绩；不重新训练或用公开 TEST 选择感知阈值 |

## 分步任务

| 任务 | 具体工作 | 保存产物 | 完成条件 |
|---|---|---|---|
| B2-01 感知接入复核 | 读取正式感知表，核对字段、记录键、时序、来源新旧、未知与缺口 | 接入检查结果、固定输入哈希、异常清单 | 不读取真值；不回填；未知/过期不被补成正常；保持行不计新观测 |
| B2-02 联合运行入口 | 接入 B1 的反馈/控制，定义统一配置和保存目录 | 待实现的组合 CLI、配置与运行清单 | 同一记录可产出感知、反馈和命令；每个输入与来源可追溯 |
| B2-03 同输入策略对照 | 在固定感知及反馈输入上比较固定提示、响应驱动、踱步分支；必要时单因素检查渐弱/间距 | 对照表、命令与生命周期审计、失败案例 | 策略不得改变输入或各自生成有利响应；无真值项目不填零错误 |
| B2-04 联合异常验收 | 核对缺测、倒序、断档、跨记录、方向拒识、反馈未知、慢响应、超时与结束撤销 | 验收矩阵、失败原因及修复范围 | 未通过项明确，所有活动提示有结束，来源及代理语义不混淆 |
| B2-05 展示数据包 | 形成标准保存包、图表和简短案例说明，交给工业设计 | 下表规定的导出文件与图表 | 新环境可复现；展示能只读保存输出；参数、来源和字幕可核对 |

B2-01 可立即开始，B2-02 起依赖 B1 对应产物。当前没有自动串联全部正式模块的组合入口；上表是待实现任务，不是已有 CLI 的能力声明。

## 评价分层

| 层 | 报告内容与边界 |
|---|---|
| A 组分类 | 保留已有锁定 TEST 的 P/R/F1、方向 macro-F1、混淆计数、支持分母；原始/融合分列 |
| B1 反馈 | 有独立真值才计算分类/事件指标；缺乏真值时给代理判据、有效观察覆盖、实例与不可评价原因 |
| 控制行为 | 首次提示延迟、误提示、无响应有效时长、切换次数及原因、提示时长、超时与退出 |
| 工程约束 | 来源过期撤销、无跨记录状态、目标范围、节拍/踱步时长一致、命令最终关闭 |
| 来源 | 真实 IMU 推理、IMU 代理、构造候选、模拟响应分别标记 |

接收复核应明确现有误报和方向覆盖损失对系统演示的影响，不作为 A 组尚未交付的训练事项。既有 TEST 可以用于固定版本的联合回放，不能描述成新增独立模型测试；后续算法/阈值开发使用 TRAIN/开发验证或新数据。

原始事件的一次报警重叠、冻结时间覆盖、窗口 F1 与提示触发分别统计。模拟响应只验证控制行为，不推导患者恢复时间或临床成功率。运动代理没有位置真值时，不能报告真实向前迈步成功率。

## 最终导出包（待实现）

| 文件 | 内容 |
|---|---|
| `perception_runtime.csv` | 正式 A 组感知输出，保留版本、来源与可用时间 |
| `feedback_runtime.csv` | B1 反馈状态、质量、来源、种类及解释 |
| `commands.csv` | 命令时间、启停/更新、事件、脚印/声音参数、切换原因 |
| `evaluation_truth.csv`（适用时） | 独立评价真值；缺真值注明不可评价，不伪造 |
| `metrics.json` / 对比 CSV | 分层模型成绩、策略工程行为及未评价项 |
| 配置、运行说明、`MANIFEST.json` | 固定版本、输入/输出/模型哈希、来源清单、重现入口 |
| 图表与案例说明 | 一条真实感知/反馈过程、一条有明确模拟来源的策略过程及失败例 |

数据包内所有文件使用同一记录身份和时钟约定；真值单独存放，展示入口只读保存结果。工业设计所需字段与来源在包内说明清楚；双方检查同一命令驱动的画面和字幕，不让展示端重新执行控制决策。
