# A2 方向识别与提前转向预测

本交付提供两个独立任务的训练、评价和无标签推理。[A1+A2 感知交接](fusion/README.md) 提供来源对齐、事件导出和英文真实回放图；独立验收与四模块联调仍按任务书完成。

展示主线确定为“当前方向识别为主要成果，提前预测保留为可行性研究”。
可直接放入汇报的高清图、汇总 CSV、中文图注和讲稿见 [展示结果包](presentation/README.md)。

## 输入和人员划分

采用 FoG-STAR v3 的背部及左踝加速度 xyz（g）、角速度 xyz（deg/s），60 Hz。
沿用 `config/fog_selected.json` 的 14 人 TRAIN 和 4 人开发验证划分；不对 TEST
提取特征或计算成绩。原始文件 SHA-256 必须与固定配置匹配。

每个记录独立切 120 点窗口，步长 30 点。窗口首尾跨度为 119/60 秒，结果从末点才可用。
不插值、不补零修复缺失信号；缺测或不连续窗口输出 unknown。错序时间拒绝运行。
运行入口只读取传感器、时间和记录身份，标签不参与特征或推理。

## 当前方向

目标为 straight / left / right / unknown。活动 1/7/6 分别映射直走/左转/右转。
两秒窗口中某一映射类别占比至少 80%，且末点仍属于该类，才赋予该类别；
其余活动、明显混合窗口和方向刚切换的边界输出 unknown 目标。

模型为 300 棵树的随机森林，叶节点最少 2 个样本，类别权重 balanced_subsample，
随机种子 5412。比较完整特征和重力投影特征两个方案。216 维完整特征包含各轴带符号均值、标准差、RMS、分位数、差分，
四个半秒段的均值/标准差、0.5–3/3–8/8–20 Hz 能量和重力方向上的角速度。
重力投影方案只保留背部与左踝各 6 维角速度统计，共 12 维。
所有特征仅使用完整输入窗口。重力投影避免预先假设传感器 z 轴就是竖直转向轴。

提供一个可解释对照：背部角速度在窗口平均重力方向上的投影，符号和阈值仅在
TRAIN 上按三类 macro-F1 选取。它不具备完整活动拒识能力。

## 提前转向

独立训练 h=0.5 秒和 h=1.0 秒两个模型，使用相同特征和随机森林配置。
以输入末点 t 为决策时刻，预测 `[t+h, t+h+0.5)` 内是否发生 Walk→Turn-left/right
标注起点。正例的实际提前量位于 `[h, h+0.5)`；不把输入窗口内已经发生的转向
算作提前预测。二者是不同目标时间段的独立任务，不能直接把成绩差解释为纯提前量效应。

输入两秒全为 Walk 时，目标为 left / right / no_turn。负例采用自然每 0.5 秒网格，
包括无即将转向及走向其他非转向活动的过渡，不对验证集做类别平衡抽样。
非全 Walk 输入标为 unknown，模型学习拒识；未来区间不足或断档不参加评分。
同一参与者的全部片段在同一集合，重叠窗口不跨训练/验证。

未来活动仅生成离线目标；运行入口无需知道当前是否为 Walk。
运行的 `task_prediction=no_turn` 表示目标时间段内未预测转向，`direction=unknown`，
不据此判断当前直走。`task_confidence` 保留任务置信分数。

## 评价含义

- 主准确率：在有效且目标明确的三类窗口上评分，拒识记为错误。
- macro-F1：对三类分别算 F1 后平均，防止多数类掩盖转向漏检。
- 覆盖率：上述明确目标中未拒识的比例；另报接受样本准确率。
- 完整流评价：包含 unknown 目标的四类混淆矩阵，拒识覆盖与主成绩分开解释。
- 提前任务额外报告：无转向多数类基线、左右召回、事件漏检、可评价与不可评价
  转向事件、实际提前量及负观察时间内的误报事件/分钟。相距不超过 0.75 秒的
  错误转向警报合为一次，时间分母是自然网格的负类有效观察时长。

仅在开发验证集上比较上述两个特征方案，并从 0/0.4/0.5/0.6/0.7/0.8 中选择拒识阈值，优化四类 macro-F1。
重力投影方案是在首轮完整特征结果偏保守后加入的开发比较，保留首轮结果目录。
因此成绩是开发验证结果，包含模型选择和阈值选择影响，独立最终评价待完成。
无转向占比很高时，必须同时阅读左右召回和 macro-F1；准确率本身不足以支持部署。

## 运行

Python 3.12，在项目根目录安装 `requirements-a2.txt` 和本项目。首次获取数据可用
仓库下载脚本，A2 仅使用 `data/raw/fogstar/sensor_data.csv`。

```bash
python -X utf8 scripts/train_a2_turning.py --task current --output reports/a2_current_NEW
python -X utf8 scripts/train_a2_turning.py --task preturn --output reports/a2_preturn_NEW
```

每个任务目录保存 `model.joblib`、`metrics.json`、四类混淆矩阵、无真值
`direction_runtime.csv`、独立 `evaluation_truth.csv` 和失败样例；提前任务另有事件支持审计。
顶层 `results.json` 保存固定划分、原始数据/代码/配置哈希和运行依赖版本。

```bash
python -X utf8 scripts/predict_a2_turning.py --model reports/a2_current_NEW/current/model.joblib --input INPUT.csv --output reports/a2_runtime_NEW.csv
```

推理输入只需 timestamp、subjectID/sessionID/taskID 及 12 个传感器通道。
只加载可信来源的 joblib 模型。`available_at_s` 是离线回放的信号末点，未叠加
设备上的计算延迟；实时部署需在实际完成推理后赋予可用时刻，并落实来源有效期。

真实准确率与局限见 [结果报告](RESULTS.md)。
独立二分类、短时变化和双踝不对称研究见 [提前转向二分类](PRETURN_BINARY.md)。
