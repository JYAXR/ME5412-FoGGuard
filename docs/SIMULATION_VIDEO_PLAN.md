# 演示与汇报方案

## 目的

展示真实 IMU 的冻结/方向判断过程、运动反馈判据、提示切换逻辑和策略对照。最终画面由保存的模块输出驱动，便于复现和答辩。

## 材料与负责人

| 内容 | 算法材料负责人 | 最终表达 |
|---|---|---|
| 冻结模型流程与比较 | A1，已交付 | 工业设计整合图表 |
| 当前方向与转向前任务 | A2 | 工业设计制作方向过程演示 |
| 运动反馈与前进/踱步切换 | B1 | 工业设计制作人物、脚印和声音展示 |
| 同条件策略比较及失败案例 | B2 | 工业设计整合结果页 |

A2/B1/B2 先交付曲线、表格和保存时间线，算法任务不包含最终 3D 制作。

## 演示场景

| 场景 | 必须看清的内容 |
|---|---|
| 正常行走 | 方向、低冻结分数、无救援提示 |
| 左转与右转 | 方向结果、置信度、未知边界 |
| 持续冻结 | 分数、事件确认和提示启动时刻 |
| 提示后有响应 | 反馈来源、响应判据和下一步目标 |
| 提示后持续无响应 | 有效观察时长、进入原地踱步的原因 |
| 原地交替后再尝试前进 | 交替计数、返回前进条件 |
| 缺测或过期 | 未知状态、提示撤销与原因 |
| 恢复或超时 | 退出条件和命令结束 |

## PPT 建议顺序

项目问题与目标、系统设定与分工、A1 三方法实现和效果、A2 方向结果、B1 反馈与策略、B2 联合比较、最终演示、能力边界。只使用对应模块已经验收的结果。

## 展示规范

真实信号、真值、模型判定、运动代理和模拟响应使用清楚的标签。脚印示意坐标不表示测得的足部位置。无独立前进位移真值时不报告真实迈步成功率；模拟案例不称为患者疗效。

B2 交付统一时间线、配置和指标，工业设计使用同一版本生成现场演示、备用视频与截图。界面不重新计算模型或控制规则。具体职责见 [工业设计任务书](tasks/DESIGN.md)。
