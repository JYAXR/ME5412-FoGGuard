# 新模型的开发验证片段补充复测

本实验由我们接收队友正式模型包后运行，没有重新训练模型、没有改阈值。固定随机抽取 24 段开发验证数据，涉及四位参与者、17 条记录；每段预留 6 秒历史、随后评分 20 秒，每 0.5 秒产生一个 2 秒窗口。计划 960 个窗口，其中三个冻结模型共同可用 920 个，阳性 189 个。无法判断的窗口没有当成正常。

| 模型 | 准确率 | 冻结检出率 | 误报窗口 | 漏报窗口 |
|---|---:|---:|---:|---:|
| 左踝历史 RF | 83.3% | 91.5% | 138 | 16 |
| 双踝 RF | 83.7% | 84.7% | 121 | 29 |
| 左踝 CNN | 84.7% | 59.8% | 65 | 76 |

这些数据参与过模型开发，窗口也有重叠；不是新的独立 TEST。队友按参与者留出的正式 TEST 成绩应单独引用，不用这里的数字替代。

另检查原始数据、两档人为噪声、右踝角速度连续缺失、缺少通道、倒序和重复时间戳，共 7 种条件，4 模型合计 672 次运行。噪声条件下冻结 F1 下降；右踝缺失使双踝可评分窗口从 920 降至 759。异常接收行为保存在 CSV 中，没有为了得到理想结果改动队友模型。

方向原始输出在 514 个有效且方向明确的窗口上准确率为 68.1%；固定融合结果为 44.4%，其中未知拒识也计为未判断正确。两者覆盖不同，需要保留分母和阶段名称。

文件：fog_model_comparison.csv、paired_noise_missingness.csv、event_coverage.csv、invalid_input_checks.csv、RESULTS.json。independent_verification.json 是该次冻结实验的复核，source_provenance.json 是当时保存的来源。它们的代码哈希记录对应原实验，后续提示模块新增不改变当时的模型成绩。
