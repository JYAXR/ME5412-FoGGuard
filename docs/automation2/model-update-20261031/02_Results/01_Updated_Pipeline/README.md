# 新版提示流程对照

使用相同新模型输出和同片段 IMU 代理反馈，比较 Fixed、Feedback only、Countdown、March 和 March no fading 五种配置。真实数据 24 段共 120 次运行，另外 24 个构造场景共 120 次，共 240 次。

真实来源使用队友锁定的双踝 RF 冻结结果与当前方向模型结果，采用团队既定融合配置。构造场景单独声明为 constructed_rule_fixture，覆盖 8 类条件 × 3 个方向，不经过训练模型推理，不当作真实患者测试。

| 配置 | 真实数据提示启动次数 | 累计提示时间 |
|---|---:|---:|
| Fixed | 14 | 30.85 秒 |
| Feedback only | 9 | 22.92 秒 |
| Countdown | 9 | 22.92 秒 |
| March | 9 | 22.92 秒 |
| March no fading | 9 | 22.92 秒 |

运动反馈配置只在反馈有效时提示；固定方案不要求反馈，因此不能把这张表当作哪种方案对患者更有效的排名。

开启与关闭渐弱的提示时长相同；开启渐弱改变退出前的强度。两种备用方式在真实片段中没有进入备用阶段，无法用这些真实片段评价备用差异。构造场景中各备用配置有 9 次进入与 9 次超时返回，核对了分支行为。

运动代理不提供脚别和落脚距离，所以测得的步长误差为不可评价；所有配置使用 0.40 m 示意目标间距。视觉强度积分是软件命令量，不是患者效果指标。

- summary.csv：按真实/构造来源和配置汇总。
- runs.csv：240 次运行的指标，包括退出原因。
- paired_comparisons.csv：相同案例下与 March 的配对差异。
- RESULTS.json：模型、配置、输入来源哈希和范围限制。
- 独立复核在 ../../05_Verification/updated_pipeline_independent.json。
