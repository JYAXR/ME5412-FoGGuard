# 基于真实信号随机生成模拟数据

24 段真实开发验证片段，每段生成 3 个随机版本，共 72 段。每个传感器通道施加随机比例、偏移和噪声，时间、记录身份及缺失位置保持不变。三个冻结模型和一个方向模型使用同样的 72 段数据，共运行 288 次。

参数固定为工程假设：比例 0.97–1.03；加速度偏移 ±0.003 g、噪声标准差 0.005 g；角速度偏移 ±0.3 deg/s、噪声标准差 0.5 deg/s。没有训练新模型或调整模型阈值。

| 冻结模型 | 原始准确率 | 三个扰动版本平均准确率 |
|---|---:|---:|
| 左踝历史 RF | 83.3% | 82.4% |
| 双踝 RF | 83.7% | 81.8% |
| 左踝 CNN | 84.7% | 84.5% |

与原始输入相比，各随机版本中判断变化的窗口数为：历史 RF 10 / 10 / 10；双踝 RF 21 / 23 / 24；CNN 5 / 5 / 5，分母各为 920 个共同有效窗口。

方向模型在 514 个有效且方向明确的窗口上，原始准确率 68.1%，三个版本分别为 68.3%、68.3%、67.7%；未知输出按未判断正确计入。

这是稳定性补充测试。源标注被沿用，未对生成版本重新人工标注；不能保证扰动一定保持真实生理状态。数据来自相同的四位开发验证参与者，各版本和相邻窗口相关，不能当作新增患者或新的独立 TEST。
