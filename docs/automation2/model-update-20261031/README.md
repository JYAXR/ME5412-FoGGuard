## 本轮做了哪些测试

| 工作 | 输入与规模 | 用途 |
|---|---|---|
| [模型补充复测](02_Results/03_Model_Validation/README.md) | 24 段开发验证数据 × 7 条件 × 4 模型，672 次 | 比较模型输出、噪声、缺失和异常 |
| [随机生成信号](02_Results/02_Generated_Variants/README.md) | 每段 3 个版本，共 72 段、288 次模型运行 | 检查小幅比例、偏移和噪声下的稳定性 |
| [新版提示流程检查](02_Results/01_Updated_Pipeline/README.md) | 24 段真实回放 + 24 个构造规则场景，各比较 5 种配置，共 240 次 | 核对接入、启停、渐弱、备用与失效处理 |
| [随机接口检查](02_Results/04_Interface_Checks/README.md) | 32 轮、320 项检查 | 核对源输出接收规则，不测分类准确率 |

这些是不同范围的实验，不能相加当成独立患者数。真实片段属于已查看的开发验证集；A 组的独立参与者 TEST 结果仍由 [原报告](../../a_group/README.md) 说明。

本轮开启与关闭渐弱的真实数据提示时长均为 22.92 秒，渐弱改变的是退出前的强度。真实数据没有触发备用条件，备用分支由单独标明的构造场景检查。本轮运动代理不提供真实落脚位置，不报告新的落脚间距误差。

## 检查与边界

本机完整检查为 356 项测试通过；最近的相关 31 项测试再次通过，Ruff 和差异检查通过。独立核对了新版 240 次运行、69,147 行命令，UI 导出 7 条时间线共 1,897 帧逐项对应保存命令。证据见 [检查记录](05_Verification/README.md)。通用 OOF 原始数据审计本轮为 NOT_RUN。

模型权重、原始传感器、完整真实个人记录、虚拟环境、汇报稿和 PPT 没有提交。本次没有新增旧 560 次实验结果，也没有放入已取消的三张提示流程图。旧文件继续保留。

UI 时间线是保存输出，最终界面与人物动画仍由第五位制作。运动迹象代理未经患者参数校准；模拟脚印位置是示意目标，工程检查不代表患者疗效。
