# 项目说明

## 目标

构建一个可复现的步态辅助研究原型，完成冻结检测、方向判断、响应观察和提示决策，并提供可用于汇报的算法证据与完整过程展示。

目标使用流程为：正常行走时监测；冻结持续确认后显示前方或转向脚印并给出节拍；提示后观察运动响应；有效观察中持续无响应时进入原地交替踱步；取得可靠响应后返回向前提示，再按恢复条件退出。

## 系统设定

| 项目 | 设定 |
|---|---|
| 主要数据 | FoG-STAR，60 Hz IMU；冻结和活动标签独立 |
| 冻结任务 | 已完成两秒窗口的冻结 / 非冻结检测，每 0.5 秒更新 |
| 方向任务 | 直走、左转、右转、不确定；A2 另行评价转向前方向预测 |
| 反馈任务 | 从有效运动观察给出动作证据、未观察到动作或未知，保留来源与可靠性 |
| 提示输出 | 屏幕中的脚印目标与声音节拍状态 |
| 备用策略 | 有效反馈支持下，从迈步提示切换原地左右交替踱步 |
| 展示方式 | 算法曲线、状态时间线、最终可视化和演示视频 |

冻结和转向可以同时发生。停止运动不直接等于冻结，低冻结分数也不直接等于迈步成功。

## 项目设计贡献

项目将感知结果与提示后的运动观察共同用于提示切换，并为每次判定保留时间、来源和原因。重点验证三件事：真实信号上的冻结与方向判断是否有效；响应信息是否支持策略切换；固定和响应驱动策略在相同工程输入下有什么差异。

三项设计需要各自的实验支撑。A1/A2 已完成固定独立测试，结果及性能限制见 [A 组报告](a_group/README.md)。提前转向未达到可用水平；运动代理和四模块闭环由对应成员完成验收。

## 两部分算法工作

前半部分由 A1、A2 完成：真实信号经过冻结和方向模块，形成按记录与可用时刻对齐的感知时间线。

后半部分由 B1、B2 完成：B1 估计运动响应并决定提示行为，B2 集成模块、组织相同输入下的对照和异常验收，形成可供展示读取的保存输出。

每个部分都要交付过程证据。A 组至少提供原始信号、真值与模型输出对照；B 组至少提供响应证据、状态转换、提示原因与策略对照。工业设计据此制作最终表达。

## 数据与结果边界

- 真实数据标签只用于训练目标或离线评价，运行控制不读取真值。
- 开发验证用于方案比较；正式效果表使用固定独立测试，分别标明分母与来源。测试参与者已用于最终评分，后续调参需要新的独立评价数据。
- 转向前任务使用标注转向起点构造目标，提前方向预测不等于已测得主观意图。
- IMU 动作代理不直接测量向前位移。没有独立真值时，不报告真实迈步成功率。
- 模拟响应验证控制行为；不能据此推导患者疗效。
