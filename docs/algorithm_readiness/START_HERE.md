## 复现

使用项目 Python 3.12 环境，另装静态图依赖：

```powershell
python -m pip install -r requirements-readiness.txt
python -X utf8 scripts/run_algorithm_readiness.py
```

该入口使用原数据和原参数重训五折受试者隔离随机森林，依次生成识别核验页、独立工程演示与新审计。输出采用新的 reports/readiness_时间戳/ 目录，不覆盖历史结果。

已具备本轮训练结果时，可用 `--baseline-dir reports/readiness_20261028` 复用 baseline_training.json 和 baseline_oof.csv；运行状态会明确标为 REUSED_SAVED_OOF，不称为本次重训。

原始数据、模型、逐窗预测、片段信号与临床表不提交 Git。新的 reports/readiness_*/ 已忽略。静态图片和本地页面是生成物；需要共享时导出选择后的材料并核对来源。

## 检查输出

- audit/index.html：本轮总览，链接真实数据交互页与独立策略演示。
- audit/record_support.csv：全部原始记录的通道支持与 OOF 覆盖；无预测记录仍在表内。
- audit/preturn_positive_candidates.csv：从 Walk→左/右转标注提取的提前 0.5/1 秒正候选。只有可行性，无预测性能；负例尚需构建。
- audit/frozen_folds.json：冻结原五折参与者划分，不重新挑选有利划分。
- audit/a_to_b_runtime.csv：当前方向/冻结事件、时效、折编号与不可用反馈占位字段，不含 truth_*。
- audit/evaluation_truth.csv：按记录和窗口键单独保存评估标签。
- audit/real_commands.csv：真实留出候选经现有事件/控制链的输出，没有虚构落脚输入。
- audit/simulated_march_commands.csv：构造输入与模拟响应驱动的踏步案例，和真实识别结果分开保存。
- audit/figures/：PNG/SVG，包含混淆矩阵、通道支持、真实 TP/FP/FN、转弯前输入片段和模拟状态切换。
- audit/manifest.json：数据、OOF、训练报告、关键源码和输出哈希。
- recognition/：原核验器对重新生成 OOF 的完整复核、逐人指标、事件覆盖与交互页。

## 已确定的证据边界

公开 v3 文件列表与字段说明已核查：[Zenodo 17838806](https://zenodo.org/records/17838806)。发布内容有 IMU、活动与 FoG 标注，没有列出原始视频、逐步落脚真值、前进位置或提示日志。标注来源于视频不等于公开包提供了视频。本文不对作者未公开的数据作结论。

活动标签可以构建“转弯前方向”研究目标，但它是活动起点代理，不直接测量主观意图。前置审计要求输入末端早于起点 h 秒、历史 120 点连续且均为 Walk、所需通道有限；仅导出正候选，不训练意图模型。若窗口不满足条件，保留排除原因。

左右踝信号可以支持步态动作代理的开发；没有独立步/位移真值，本轮不能计算真实“没迈出去”准确率。反馈占位状态是 not_estimated，valid=false，不伪造 no_step。

原窗口使用窗口内双向滤波；完成窗口末端输出时，窗口内样本均已可用。原短缺失插值在整段记录上进行，可能在窗口尾使用未来的右端点。历史离线基线保留不改；严格在线或提前任务需改为仅在完整可用窗口内插值、延迟输出或显式拒绝，不直接沿用离线结果宣称严格因果。

## A1 下一项具体工作

你负责冻结识别，不承担新的转向意图模型、步反馈估计器或 3D。下一步建议先做一项可解释的改进实验：**保留 2 秒基线特征，增加最近 1 秒的运动能量与变化趋势特征**，检查能否改善启动/恢复边界及站立误报。

1. 读取本轮 subject_metrics.csv、activity_metrics.csv 和 FP/FN 图，先记录假设与预期代价。
2. 保留原五折测试参与者；新特征/阈值的选择使用训练参与者内部的分组验证，不用测试标签挑方案。现有 OOB 阈值属于历史基线，不能宣称它等同于按参与者隔离的内层验证。
3. 为区分特征与调参方式的效果，比较旧特征+分组内层阈值、新特征+相同分组内层阈值；原 OOB 基线作为历史参考另列。
4. 导出新 OOF；重算 precision/recall/F1、按原始真值事件的覆盖/误报/延迟、逐人表现、缺测覆盖。模型输出在窗口结束后才可用。
5. 输出同一真实片段的基线/改进曲线和一张对照表，保留表现下降的参与者和失败例。结果不好也照实交付，不反复用同一测试集挑优胜方案。

该改进仅是下一项实验设计，本轮没有执行，不提前声称性能提升。新的选模、阈值规则和评价口径先写入独立配置，再开始训练。
