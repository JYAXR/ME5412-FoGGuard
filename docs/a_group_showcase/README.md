# FoGGuard A-group unified charts and data

Open index.html locally. This collection needs no server or internet. Figures are English PNG/SVG, with short explanations and aggregate CSV data.

Order: workflow/methods, evaluation scope, FoG, current direction, FoG fusion, synchronized TEST replay. FoG confusion counts and development values are supporting material.

TEST is the main effect report. Development is only method-selection context. Original model outputs, source results and the fixed replay selection are unchanged.

See FIGURE_CATALOG.csv for figure/caption/data mapping and data/DATA_DICTIONARY.md for units.
