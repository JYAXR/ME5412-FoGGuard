# FoG-STAR 多任务识别基线

更新日期：2026-10-21。

> 责任边界：本文描述的是机器人 1 交付的“数据与模型”基线。模型会输出转向候选类别，但机器人 2 仍负责情境模块选择、时间逻辑、控制器接入和端到端验证。

## 数据选择

主训练数据改用 FoG-STAR v3.0。原始文件来自 Zenodo DOI
`10.5281/zenodo.17838806`，许可为 CC BY 4.0。`sensor_data.csv` 的官方 MD5 为
`952a37ab147da35e6d4e7a1e9bac44cb`。原始数据只保存在被 Git 忽略的
`data/raw/fogstar/`，不得提交到仓库。

FoG-STAR 包含 22 名帕金森病参与者、左右脚踝、腰背和手腕四个 60 Hz IMU。
每个 IMU 提供三轴加速度与三轴角速度。活动标签分别包含直行、右转、左转和
其他姿态，FoG 是独立二值标签。因此一次窗口可以同时是“左转”和“FoG”。

## 为什么使用两个输出头

把所有窗口强制压成直行、左转、右转、FoG 四个互斥类别，会丢失转弯冻结的
方向信息。本基线训练两个独立分类器：

1. FoG 头输出冻结概率；
2. 情境头输出直行、左转、右转或 `other` 安全拒绝类。

面向界面或提示控制时，FoG 状态具有显示优先级，但方向预测仍然保留。坐、站、
姿态转换及方向不明确的边界窗口作为 `other` 参与训练，避免模型被迫输出左右转。
当前默认
输入是左脚踝和腰背共 12 个通道；前者提供文献中效果较好的 FoG 信号，后者保留
躯干绕垂直轴转动的信息。

## 预处理与特征

- 2 秒窗口、0.5 秒滑动；窗口不跨参与者、会话或任务。
- 小于等于 0.1 秒的内部缺失段线性插值；更长缺失段会切断有效序列。
- 原始有符号均值和中位数专门保留低频转向信息；其余动态特征采用文献一致的
  0.5–20 Hz 四阶 Butterworth 带通滤波。
- 每个通道提取标准差、RMS、范围、四分位距、相邻差以及
  0.5–3 Hz 和 3–8 Hz 能量等特征。
- FoG 头不使用原始均值和中位数，减少佩戴姿态与参与者差异造成的偏置；每个训练
  折仅用该折训练数据的随机森林 OOB 预测校准 FoG 阈值，再应用到不可见测试参与者。
- FoG 和方向标签均要求至少覆盖窗口的一半；无明确方向的窗口进入 `other` 类。

## 训练与新数据推理

```bash
python scripts/download_fogstar.py
python scripts/train_fogstar_baseline.py
python scripts/predict_fogstar_baseline.py path/to/new_sensor_data.csv
```

训练使用按参与者分组的五折交叉验证，重叠窗口不会跨参与者泄漏。默认模型和报告
分别写入 `artifacts/fogstar_multitask_baseline.joblib` 与
`reports/fogstar_multitask_baseline.json`。

新数据至少需要以秒为单位的 `timestamp`，以及训练模型对应的 `ankleL_*`、`back_*` 十二个列，
加速度单位为 g、角速度单位为 deg/s、采样率为 60 Hz，传感器轴向必须与训练数据
一致。受试者、会话、任务及标签列可省略。

## 机器人 1 到机器人 2 的交接规则

机器人 1 交付训练好的模型及逐窗口推理结果；机器人 2 消费这些结果并完成系统级整合。建议按以下顺序接入：

1. 校验输入通道和采样率，再调用批量或实时窗口推理。
2. 原样保存 `fog_probability`、`is_fog`、`direction` 和 `direction_confidence`。
3. 将 `direction=other` 视为未知/拒识，不可强制分配为直行、左转或右转。
4. 在模型输出之后增加时间平滑、事件合并和安全门控。
5. 再映射到机器人 2 维护的情境接口与 `ControllerContext`。

`state` 是便于评估的模型级四状态标签，其中 FoG 优先；它不是可直接触发控制或提示的安全决策。详细字段契约和接入清单见 `docs/ROBOT1_HANDOFF.md`。

## 当前基线结果

在 9,636 个有效窗口上进行五折受试者分组交叉验证，训练折内 OOB 阈值中位数为
`0.31`。结果如下：

| 任务 | Macro-F1 | Balanced accuracy | 补充结果 |
|---|---:|---:|---|
| FoG 二分类 | 0.749 | 0.765 | AUC 0.858，FoG recall 0.657 |
| 直行/左转/右转 | 0.827 | 0.757 | 不明确窗口可拒绝为 `other` |
| 四状态最终输出 | 0.762 | 0.725 | FoG 优先于方向 |

这些是窗口级结果。当前还没有把连续阳性窗口合并成独立事件，因此尚不能报告可靠的
事件召回率、误报事件/分钟或首次检测延迟，也不能直接驱动真实提示。

## 证据边界

FoG-STAR 只有 22 名参与者，并主要在停药状态下采集。本基线用于课程原型与数据
管线验证，不用于临床决策。下一阶段应比较随机森林与 1D-CNN/TCN，并在独立数据集
上报告 FoG 事件召回率、误报次数/分钟、首次检测延迟及方向 macro-F1。
