# FoG-STAR 数据与识别任务

FoG-STAR 提供 22 位参与者、106 条记录、四个位置的 60 Hz IMU，以及独立的活动与冻结标注。数据 DOI 为 `10.5281/zenodo.17838806`，许可 CC BY 4.0。下载脚本校验文件，原始数据保存在 Git 忽略目录。

## 两个独立感知目标

A1 识别冻结/非冻结，A2 识别直走/左右转/不确定。转弯时可以发生冻结，因此两者不能合并为四个互斥类别。A2 的转向前任务需要另行定义输入截止时刻和未来方向目标。

## A1 模型

A1 提供左踝历史特征 RF、双踝 RF 和左踝 CNN，统一入口为 `scripts/predict_selected_fog.py`。实现与真实效果见 [三模型说明](a1/SELECTED_METHODS.md)，输入单位及缺测规则见 [数据格式](DATA_SCHEMA.md)。

## A2 任务

活动 1、6、7 对应直行、右转、左转，其他活动和混合边界需要拒识。当前方向标签描述动作，转向前预测采用标注起点代理；两者分别评价。训练/验证按参与者隔离，不能将同人的重叠窗口随机拆开。

方向与 A1 的融合由 A2 实现，见 [A2 任务书](tasks/A2.md)。共享适配工具中的组合模型和合成规则服务接口与工程检查，不属于 A1 三模型的效果表，也不替代 A2 正式任务的评价。

## 证据限制

公开信号可支持运动代理开发，但未提供本项目所需的独立逐步前进位移真值、真实提示日志与响应对照。冻结结果、动作代理和策略仿真分别报告。
